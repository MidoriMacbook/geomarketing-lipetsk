# Local type assets

Golos Text (400–800 variable) and Unbounded (600–700 variable), Cyrillic and Latin WOFF2 subsets.
Retrieved 16 October 2026 from Google Fonts / fonts.gstatic.com. SIL Open Font License 1.1 files are included separately for each family.

Sources:
- https://fonts.google.com/specimen/Golos+Text
- https://github.com/google/fonts/tree/main/ofl/golostext
- https://fonts.google.com/specimen/Unbounded
- https://github.com/google/fonts/tree/main/ofl/unbounded

The UI uses font-display: swap and system fallbacks. No runtime external font requests are needed.
