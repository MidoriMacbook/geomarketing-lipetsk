# Начальные снимки OpenStreetMap

JSON в `snapshots/` содержат `fetched_at` (Unix UTC) и `data`.
Дома: `[широта, долгота, оценка жителей]`; конкуренты: `[широта, долгота]`.
Имя файла включает тип данных, район, координаты центра и радиус.

Елецкий и центр перенесены из ранее загруженного кэша проекта. Для этих двух
районов `fetched_at` — исходное время сохранения файла на 11 октября 2026 года,
а не время ревизии объектов в OSM. Университетский обновлён после исправления
координат района по [OSM relation 17717422](https://www.openstreetmap.org/relation/17717422).
Для него 11 октября 2026 года использована разовая выгрузка основного OSM API
`/api/0.6/map` по рамке центра с радиусом 1400 м (1000 м + запас для конкурентов),
поскольку Overpass возвращал 504/500. К выгрузке применены те же теги домов и
бизнесов и формулы оценки населения из `osm.py`. Центры контуров конкурентов —
центры их ограничивающих прямоугольников. Последующие обновления идут через Overpass.
Снимки служат стартовой копией, пользователь может обновить их через интерфейс.

Геоданные © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright),
[Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Значения жителей рассчитаны проектом на основе тегов OSM и являются оценками.
Данные не включают персональную информацию о жителях.

При обновлении функций запас границы для конкурентов исправлен: не меньше
радиуса соответствующей категории (500 м для аптек и 450 м для салонов).
Снимки этих двух категорий заново получены 12 октября из выгрузок с запасом
500 м; имена включают `_halo500`/`_halo450`. Старые копии с запасом 400 м больше
не используются, чтобы не терять конкурентов у пограничных рекомендаций.

## Дополнительные категории (12 октября 2026)

Для продуктовых магазинов (shop=supermarket/convenience), пекарен (shop=bakery)
и салонов красоты (shop=hairdresser/beauty) добавлены отдельные снимки всех
трёх районов. Они получены из небольших XML-выгрузок основного OSM API 0.6.
Магазины и пекарни используют запас 400 м; для них в Университетском использована
сохранённая выгрузка от 11 октября. Салоны используют запас 450 м и обновлённые
выгрузки всех районов от 12 октября, как и аптеки с запасом 500 м. Дата в JSON
соответствует исходному файлу выгрузки.

Инструмент подготовки: `scripts/import_osm_competitors.py`. Например:

```bash
python scripts/import_osm_competitors.py --district center --business bakery --source center-source.osm
```

Инструмент проверяет корень OSM и покрытие `<bounds>` до записи, затем фильтрует
теги общего каталога `businesses.py`, рамку и дубликаты. HTML-ошибка, неполная
выгрузка или неполная геометрия подходящего объекта отклоняются; прежний снимок
не перезаписывается. Успешная полная пустая выгрузка допустима.
Контуры используют центр ограничивающего прямоугольника. При неполных отношениях
импорт прекращается, чтобы не вычислять центр по обрывочной геометрии.
Сырая XML-выгрузка в репозиторий не входит. Пустой список означает, что объектов
с соответствующими тегами не найдено в полученной выгрузке; это не подтверждает
отсутствие реальных конкурентов. Полнота данных зависит от заполнения OSM.
