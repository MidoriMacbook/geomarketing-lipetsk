# Состояние проекта

Актуально на 1 ноября 2026 года. Рабочий сайт: https://geomarketing-lipetsk.onrender.com/.

Flask обслуживает страницу и API одного origin; Waitress слушает порт из окружения.
Код сервера разделён на routes, services, domain и utils. На клиенте — обычные
ES-модули и Leaflet; React используется в необязательной локальной анимационной
сборке первого экрана. Material Web, шрифты и лицензии включены в репозиторий.

Доступны десять областей, своя область, десять категорий бизнеса, до трёх
рекомендаций, сохранения, исследования, сравнение, CSV и печатный отчёт.
Хранилища принадлежат браузеру: учётных записей и синхронизации устройств нет.
Web Locks защищает запись между вкладками; без него доступны чтение и экспорт.

## Данные и модель

При CITY_DATA_URL сервер использует ежедневную городскую выгрузку GitHub,
при отказе — пригодную сохранённую копию или районный снимок. Без этой настройки
работает локальная загрузка Overpass. Демопримеры доступны только для шести
существующих пар район/категория; остальные пары и собственная область при
отсутствии данных получают понятный HTTP 400, а не выдуманный результат.

В новых данных сохраняются тип и ID объекта OSM, дата получения, исходные
признаки оценки жителей и основание дедупликации. Удаляется повтор одного ID;
разные близкие объекты и вероятные дубли точки/контура сохраняются с предупреждением.
Старые числовые строки, снимки и архивы читаются по прежним правилам.

Модель использует взвешенные центроиды спроса и сетку кандидатов. Балл
«100 из 100» относителен только к одному расчёту и не означает вероятность успеха.
Разные OSM ID не доказывают разные реальные дома: семь совпадающих пар
сохранены, возможное завышение и влияние на рекомендации измерены отдельно.
Число жителей оценочное; отсутствие отмеченных конкурентов не доказывает их
отсутствия на местности. Проверка схемы/хеша не подтверждает полноту OSM.

## Проверка и обслуживание

Основной CI запускает автономные Python/Node-тесты, проверки сборок и четыре
коротких браузерных сценария на контролируемых данных без Overpass/Render/тайлов.
Расширенная матрица остаётся отдельной проверкой, а не обязательной частью каждого push.
Физические телефоны, все движки браузеров и работа принтера этим не подтверждаются.

[Устройство](docs/architecture/overview.md), [запуск и проверки](README.md),
[публикация](DEPLOYMENT.md), [геоданные](data/README.md),
[проверка этапа](docs/verification/2026-11-01-reliability-and-release.md).
Исторические отчёты сохраняют факты на свою дату и не заменяют текущие инструкции.

Служебные журналы state.md/session-log.md исключены из публичной версии:
их полезные решения перенесены в архитектуру, README и отчёт. Локальные
доказательства и резервные копии истории находятся в игнорируемых каталогах.
Обычная публикация выполняется push main; перезапись старой истории требует
отдельного согласия владельца и проверенной резервной копии.
