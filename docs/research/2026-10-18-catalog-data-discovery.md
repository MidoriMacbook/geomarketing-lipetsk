# Разведка данных для расширения каталога

Дата: 18 октября 2026. Это результаты поиска, не утверждённые центры анализа.
Спецификация: ../specs/2026-10-18-catalog-and-map-colors.md; ожидается согласование.

## Доступность

Запрос place/name через Overpass: overpass-api.de — read timeout 30 s;
overpass.private.coffee — HTTP 500. Ошибочные ответы не сохранены как пустые данные.
Nominatim /search доступен; последовательный одноразовый поиск с паузой 1.1 s,
bounded viewbox 39.35,52.72,39.90,52.50, до трёх результатов.
Не использовать Nominatim как зависимость пользовательского расчёта.

## Обнаруженные зависимости

- Сейчас поставляется 18 снимков: три набора домов и 15 наборов конкурентов.
- Новым категориям R>400 нужны снимки с соответствующим halo, не прежние bbox.
- Матрица offline API уже перебирает каталог; новые области без снимков сломают её.
- API/browser tests местами фиксируют пять типов и 15 сочетаний — обновить
  согласно спецификации, сохранив прежние численные fixtures.
- map-harmony.js фиксирует розовый house и opacity>=.95 — нужен RED→GREEN
  для нового токена и менее плотной заливки; легенда тоже проверяется.
- restoreScenario отправляет input, а автоматический расчёт слушает change;
  это разделение нужно сохранить.
