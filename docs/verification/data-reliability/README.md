## Проверки

- Python проверяет границу 29/30, сочетания пропусков, пустой круг, нулевой знаменатель, старые источники и совместимость API. [Тесты](../../../tests/unit/test_data_reliability.py)
- Playwright проверяет карточки и переход к поправкам при ширинах 320, 375, 390 и 1440 px, сохранение выбранного места и карты, неизменность оценки после поправок и старый архив. [Сценарии](../../../tests/smoke/reliability.spec.js)
- Если между открытием расчёта и входом в «Мои поправки» обновилась выгрузка, интерфейс оставляет исходный результат и предлагает явно проверить обновления.
- Ручная проверка на физическом iPhone открыта. Предварительные пороги ждут сверки с 2ГИС и Яндекс Картами. Плотность продуктовых магазинов остаётся косвенным признаком, который зависит от застройки и назначения района.
