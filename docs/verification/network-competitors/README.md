Сетевой признак сохраняется в происхождении записи `city.json` как `is_chain: true`. Для опубликованной до этапа 2 выгрузки с брендовыми тегами он вычисляется при чтении по тем же правилам. ## Три веса на одной выборке

Штраф в таблице измерен в одной и той же точке — на первом месте при полном весе. Фактическое число конкурентов в радиусе указано для лучшего места каждого варианта.

При личных поправках исходный расчёт для дельты использует выбранный сетевой вес. Удалённый объект исключается из выборки, добавленный вручную учитывается с полным весом. Для архивов без сетевой настройки применяется полный вес. Снимок хранит применённое значение и поправки.
