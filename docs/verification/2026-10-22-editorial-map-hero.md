## Дополнительное проверка выпуска 23 октября

Проверка реализации диапазона 9a15e57..42ce49e нашло две существенные ошибки:
задержанный Playfair на390px менял h1 с93.25 до139.875px, а мобильный menu→map
на390×320 оставлял target на500.375px вне экрана. До исправления обе новые
регрессии воспроизводят ошибки. Теперь mobile-перенос перед «бизнеса» явный;
при очень крупном тексте container query h1 выбирает устойчивые строки слов,
без уменьшения шрифта или обрезки. Текст и естественная высота сохраняются.
close() синхронно измеряет закрытый header. Отступ шапка плюс20px задан один
раз общим scroll-padding; дублирующий scroll-margin для id удалён. Первоначальная
попытка оставить offset только для id выявила регрессию обычного Tab-фокуса
на кнопках карточек без id, поэтому общий отступ необходим и им.

hero-font-fallback проверяет h1 и обе CTA до/после шрифта в19вариантах:
360/390/430/600/601/650/700/768/900/901/1024/1100/1101/1280/1440 при100%
и390/768/1024/1440 при200%. Геометрия стабильна (≤1px), overflow
отсутствует. Whole-page CLS остаётся диагностикой: обновления Material/данных
и различия метрик глифов не объявляются нулевыми. header-anchor проверяет
menu/hero/trust/research-open на390×320 при100%/200% и390×600 при200%:
workspace96.375px приheader76px,225.6875px приheader206px; target/focus видимы.
header-focus воспроизводит RED: summary132–188px подheader206px. После общего
отступа27переходов Shift+Tab на390×320/200%,390×600/200%,1440×900/100% видимы;
например summary245–301px и save226–285px приheader206px.
Дополнительный независимый sweep обнаружил промежуточные700/901px:
слово «бизнеса» переносилось после загрузки шрифта, CTA сдвигались на41/49px.
RED добавлен в регрессию; правило container<9em стабилизирует первую фразу,
а существующее<6em оставляет крупному тексту строки отдельных слов. После
изменения все19случаев GREEN. При обычном размере1440/390 композиция прежняя,
на768/1024 заголовок получает предсказуемый дополнительный перенос.
