Целевые регрессии проверяют метку на границе 39/40, расположение координат, единое начертание действий, переход к настройкам на четырёх ширинах и выноску на низком экране. Полный smoke-набор: 50/50 пройдены. После устранения конфликта стилей первой карточки целевые проверки — 5/5.

## Воспроизведение и границы проверки

Снимки каждого пункта сняты до и после соответствующего изменения; для п. 4 итоговые кадры обновлены после устранения конфликта стилей первой карточки на 375/768/1440/1920, высота 1000 px. Использован существующий локальный smoke-сервер: браузерная фикстура оставляет 1/2/3 рекомендации и задаёт второй карточке 26 баллов для проверки метки. Это только тестовые данные; серверная формула не изменена. Внешние тайлы отключены для одинаковых снимков.

Автоматический аудит проверяет компонентные контейнеры, их радиусы, симметрию внутренних отступов, переполнения, sRGB-контраст с альфа-композицией фона и вес соседних действий. Круги карты и графические знаки сохраняют круглую форму; геометрия этих изображений не относится к радиусам карточек. Скрытые и inert-области не считаются доступным интерфейсом. Контраст над растровыми тайлами исключён из численного аудита; выноска и кнопки проверены снимком и тестом пересечения. Физические мобильные устройства в этот прогон не входят.

Индекс codebase-memory был недоступен (Transport closed); затронутые файлы проверены непосредственно по исходникам.
