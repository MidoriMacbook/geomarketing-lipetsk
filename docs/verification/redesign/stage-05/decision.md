# Выбор шапки

Выбран B: прямое название Playfair Display, курсив только в коротком «своё место». A читается так же хорошо, но акцент слогана тяжелее. C с Lora Italic мягче, однако снова вводит рукописные формы в длинное название. Основная пара Playfair Display + Golos Text сохранена.

Все три варианта сняты на 375 и 1440 px с CPU ×4. На 375 px высота hero 512 px (63% от 812 px); горизонтального переполнения нет. Статические снимки с reduced-motion, взаимодействия отдельно проверены с анимациями. Шапка не заменяется React-островом.

Кварталы окрашены в Sage, Misty Sky и Blush. Rosewood отмечает цель и её радиус. Маршрут открывается масштабируемой SVG-маской, кварталы появляются каскадом, радиус пульсирует. Меняются только transform/opacity. Движение приостанавливается вне экрана и в скрытой вкладке, отключается при reduced-motion. Без острова иллюстрация статична. Световое пятно и магнитное действие работают только в шапке при точном указателе.

Кандидат C использован только в проверке, новый шрифт на сайт не добавлен. Источник Lora Italic и лицензия SIL OFL: https://github.com/google/fonts/tree/main/ofl/lora. Для повторения сравнения нужны `tests/artifacts/fonts/Lora-Italic.ttf` и `scripts/frontend/capture-headings.mjs`.
