# Производительность

Мобильный заголовок остаётся статичным с первого HTML. Убраны размытие текста, анимация фона и тени кнопок; рабочая область больше не исчезает при прокрутке. Отклик использует opacity и transform. Мелкие подписи увеличены до 13 px.

Пять последовательных Lighthouse 13.6.0 mobile-прогонов, CPU ×4, Chrome, localhost:5057 с реальными данными. Медиана LCP 2,122 с, диапазон 2,114–2,135 с; performance 95 (93–95); CLS 0,0784 (0,0782–0,0814). Это лабораторная проверка, не измерение сети Render или физического телефона. Исходные значения — lighthouse-summary.json. Accessibility 98; замечания к именам элементов и иерархии заголовков переданы в этап 8.

Изолированный запуск `node scripts/frontend/measure-map.mjs`: 1500 синтетических домов, CPU ×4, отрисовка 188 мс; интервал кадра p95 16,7 мс, максимум 191,5 мс. Одиночная длинная пауза остаётся; проверка не доказывает устойчивые 60 fps на слабом устройстве. Синтетические точки используются только в измерении визуализации, модель не меняется.

Команды: `node node_modules/@playwright/test/cli.js test --config playwright.redesign.config.js`, `node --test tests/unit/*.test.js`, `node scripts/frontend/capture-stages.mjs 07`. Smoke: 16 проверок; unit: 93. В тесте своей области устранено случайное попадание в номерной пин после fitBounds: центр теперь выбирается на свободной поверхности карты. Скриншоты сняты с CPU ×4; перед статичным снимком включено reduced-motion для завершения счётчиков.
