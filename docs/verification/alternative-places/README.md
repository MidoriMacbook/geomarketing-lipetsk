Запасные места запрашиваются флагом `include_alternatives=1`. Роль и показатели пары сохраняются в исследовании и в сохранённом месте. Если изменились текущие параметры, сохранённое запасное место открывается на карте по исходным координатам. Пояснение спроса запасного варианта использует среднее по основным местам. В подписи рядом с запасным местом доля считается от меньшего охвата, в сравнении на карте — от объединённого, как и раньше.
