## Мобильный путь

Открыть карту → «Настроить анализ» → область → бизнес → «Найти места» →
раскрытое лучшее место. Другие места открываются нажатием. Выбор строки выделяет
маркер без сдвига карты; отдельная кнопка возвращает к карте. Ошибка оставляет
настройки открытыми. Фоновый пересчёт при смене района не прерывает редактирование.

## Подтверждённые проверки

Браузер Chromium, эмуляция касаний. Матрица:

| Размер | Результат |
| --- | --- |
| 320×568 | Две основные метрики, меню рядом с брендом, без горизонтального скролла |
| 360×800, 390×844, 430×932 | Нижняя панель, выбор, успех/ошибка, рекомендации |
| 844×390, сенсорный экран | Мобильная компоновка, прокручиваемая форма |
| 768×1024, 1280×900 | Форма возвращена в рабочую область, четыре исходных KPI |
| 320/360/390/430, текст 200% | Нет горизонтального переполнения, запуск доступен |

`mobile-analysis-flow.js`: семь размеров, порядок карты, одна форма/кнопка,
выбор бизнеса, расчёт, ошибка, фокус, KPI, карточки, сохранение и уменьшение движения.
`mobile-analysis-accessibility.js`: KPI скрыты до ответа, произвольная область,
редактирование при автоматическом расчёте, повторное открытие, Tab/Escape,
переход к сохранениям и текст 200%. Ошибок JavaScript не обнаружено.

Нативный диалог исключает фоновые элементы из последовательности Tab; переход
к интерфейсу самого браузера остаётся штатным поведением браузера. Первый Escape
закрывает выпадающий список, следующий — панель. Закрытие возвращает фокус.

До исправлений зафиксированы воспроизводимые ошибки: отсутствовала компактная
кнопка; альбомный844×390 не включал мобильный режим; позднее событие `close`
сбрасывало состояние вновь открытой панели; на 320px меню переносилось под бренд,
а число жителей занимало две строки из-за более приоритетного старого стиля.
После соответствующих исправлений эти проверки проходят.

Независимая проверка кандидата `c8a5167` выявила ещё три подтверждённых дефекта.
Касание варианта теряло фокус и закрывало список без применения выбора;
проверки усилены явным сравнением выбранных ключей. После исправления совместимого
события мыши касание меняет бизнес и район. Отдельная проверка
`mobile-choice-touch.js` прокручивает список реальным потоком touch-событий Chromium
и выбирает стоматологию; прокрутка не закрывает список и не выбирает случайный пункт.

При действительной смене бизнеса ожидающий счётчик домов оставлял «—», поскольку
его перенесённая группа не попадала в сброс. Сброс теперь охватывает обе группы.
Новый тест сравнивает итоговое число с `stats.houses`, прежде не раскрывая детали.
Явная кнопка «Показать на карте» теперь также возвращает выбранную точку в кадр
после ручного увода карты. Обычное раскрытие карточки не перемещает карту.
Для счётчика и показа места подтверждены падение на старом коде и успех после исправления.

Прежние проверки `workspace-interactions.js`, `counters.js`, `mobile-feedback.js`,
`workspace-guidance.js`, `workspace-guidance-fallbacks.js` прошли: точные значения,
клавиатура/касания, хранение, исследования, CSV/печать, отсутствие необязательных
возможностей браузера. В проверке прерывания счётчика смена бизнеса заменяет смену
района, поскольку готовый район уже автоматически запускает расчёт.

Серверные проверки: `python -m unittest discover -s tests -q` — 106 успешно.
Node: scenario-storage, field-check-storage, data-delivery, analysis-focus,
recommendation-brief — 86 успешно, ошибок нет. Структурная проверка
`python scripts/validate_project.py` — 88 файлов, без ошибок.

## Сохранённые контракты и ограничения

Сервер, маршруты API, расчётная модель, районные и городские данные, загрузка
выгрузки, Leaflet, ключи хранения, сценарии, CSV и печать не изменены.
Сопоставление с базой `0b9f78b` для этих исходников пустое. Новых зависимостей нет.

Телефонный режим ограничен 600px либо коротким сенсорным окном до 950×500px;
обычные планшеты и компьютеры сохраняют прежнюю композицию. Физические iPhone,
Android и мобильный Safari в этом этапе не проверены. Эмуляция не подтверждает
поведение системной клавиатуры, реальную безопасную область и жесты устройства.
Проверка200% меняет размер текста; системный масштаб конкретного устройства
не воспроизводится. Состояние ежедневной сборки данных не входит в этот этап.

Публикация и независимая проверка будут зафиксированы после завершения.
