# Максимумы кластеров — вариант C

Изменения расчёта ограничены `src/domain/scoring.py` и `src/config.py`. Формула спроса, штраф конкуренции, сетка 60×60 и нормирование не изменены. Контрольные суммы всех трёх поверхностей до/после совпадают.

## Правило отбора

Взвешенный K-средних: до трёх кластеров, `random_state=42`, `n_init=10`. Каждая точка сетки относится к ближайшему центроиду. Из каждой зоны выбирается максимум исходной оценки. Максимумы рассматриваются по убыванию балла; при равенстве сохраняется порядок точек сетки.

Другой кластер сам по себе не гарантирует другой спрос. Максимум исключается, если он ближе 250 м к уже выбранному месту либо общие жители составляют больше 50% населения меньшего из двух радиусов. Порог вынесен в конфиг. Худший кандидат того же кластера вместо исключённого не подставляется. Независимость здесь — правило модели, не утверждение о реальных покупателях.

Пересечение определяется по членству учтённых домов в обоих радиусах, не по площади кругов. В карточке знаменатель доли явно подписан: все учтённые жители **этого места**. Дома не объединяются; меняется только выбор рекомендаций.

## Документ и совместимость

В документе проекта изменены только три абзаца раздела «Методы»: роль центроидов, отбор мест, пояснения в карточке. Остальные формулировки и части DOCX сохранены. Документ отрендерен установленным Word и просмотрен: три страницы, текст не обрезан. Старая копия не добавляется в репозиторий.

Старые исследования остаются снимками старого расчёта. Новые поля необязательны для чтения; ключ и версия хранилища не меняются. Новые исследования сохраняют способ отбора и сравнение с лучшим.

Целевые проверки: совпадение поверхностей, повторяемость, максимум одного кластера, маленькая область, совпадающие координаты без объединения домов, один общий дом (10 из 1010 жителей), сохранение нового и старого исследования вместе.
