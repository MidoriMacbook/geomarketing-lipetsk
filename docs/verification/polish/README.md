# Полировка redesign

Работа только в `redesign` и отдельном сервисе https://geomarketing-lipetsk-redesign.onrender.com/. Main не публикуется. Физические телефоны проверяет автор проекта.

## Порядок и свидетельства

1. Загрузка: меню в HTML, мобильные блоки занимают окончательные места до JS; параметры резервируют две строки. Иллюстрация статична, кроме радиуса. Fast 3G / CPU ×4: исходный Render CLS 0,08774; после исправления локально 0,00003. Причина — перенос блоков в initMobileWorkspace, workspace менял y с 962,7 до 650,3. Регрессия загрузки проходит. Снимки и полная трасса: `01/`. Повторная проверка на Render — в итоговых метриках.
2. Панель результатов: содержимое не скрывается и не сжимается во время закрытия; высота области прокрутки меняется после остановки. Карта фиксирует высоту на время жеста, invalidateSize вызывается после завершения; touch/wheel не прокручивают страницу во время захвата ручки. 5 целевых smoke-проверок проходят. Снимки: `02/`.
3. «Листики» создавал border-radius:99px у общего прокручиваемого контейнера, обрезавший верхний и нижний пункт. У контейнера теперь 0, у пунктов одинаковые 12 px; активный фон Blush. clip-path отсутствует. Регрессия проходит; `03/`.
4. Радиус вписывается целиком с отступами над панелью после завершения прокрутки. Все четыре слоя расположены над картой в двух колонках. До исправления круг выходил за левый край (x −125), два слоя перекрывались; после круг 244×244 px внутри видимой области. Целевая регрессия и снимки `04/`.
5. Прямоугольник — выделение текста: ::selection уже Blush / Midnight Lagoon (проверено вычисленными стилями). Отдельное круглое пятно курсора с radial-gradient ограничено opacity 0,35. Под тайлами теперь светлый Sage; плавное появление 250 мс отключается при reduced motion. Снимки выделения и карты без тайлов на 375/1440 px: `05/`.
6. Пять замеров Render и холодный старт — ожидает.
7. На 768 px внутри узкой панели сохранялась старая двухколоночная сетка формы. Поля теперь идут вертикально, подписи над ними, без побуквенного переноса. Сопоставимые снимки 375/768: `07/`.
8. Строка загрузки наследовала розовый цвет маркеров (Blush на Sage). Теперь Midnight Lagoon на Sage; контраст 9,4:1. Состояние calculating и вычисленные цвета: `08/`.
9. Горизонтального переполнения страницы в исходном сравнении не было (375/375 px). Не хватало подсказки о прокрутке и сохранения контекста строки: добавлены индикатор и закреплённый первый столбец. Сравнение двух реально сохранённых мест: `09/`.
10. «Не вероятность успеха» оставлено один раз в «Оценке и данных», доступной на всех ширинах. Убрано из подробностей, подсказок баллов и диалога модели; ограничения исходных данных сохранены. Снимки и подсчёт в DOM: `10/`.
11. Исправлено «Исследование … будет удалено из этого браузера». Диалоги сохранения и очистки проверены: «список … очищен», «места останутся» согласованы. Реальный диалог удаления сохранённого исследования: `11/`.
12. В README добавлен раздел «Как показывать проект»: открыть за две минуты, при необходимости внешний GET /robots.txt; отдельно объяснено ожидание первого HTML. Это документация, снимок интерфейса не применим. Main не меняется.
13. Итоговый CLS во всех пяти прогонах — ожидает.
14. Модель C, сравнение областей и документ — ожидает.
