# Цветовая система

| Элемент | Цвет | Зачем |
|---|---|---|
| Страница и внутренние поля | Cream | Спокойный фон, ясная граница панелей |
| Основной текст | Midnight Lagoon | Контраст с пастельными поверхностями |
| Бренд, выбранное место, главное действие | тёмный Rosewood | Общий акцент, читаемый мелкий текст |
| Настройки и пояснения анализа | Sky-тинт | Объединяет действия, относящиеся к расчёту |
| Рекомендации, сохранённые места, сравнение | Blush-тинт | Объединяет следующий шаг пользователя |
| Числа и данные | A: Sage-тинт; B: Cream | В B данные не создают третью конкурирующую подложку |
| Дома | тёмный Misty Sky | Чётче видны на светлой подложке |
| Конкуренты | Rosewood, круг | Отличаются от прямоугольных зон не только цветом |
| Зоны оценки | светлый → тёмный Sage | Насыщенность обозначает порядок оценки |
| Центр спроса | пунктирный контур Midnight | Отличается формой от конкурентов и рекомендаций |

Применён B: Cream + Blush + Sky в интерфейсе; Sage только на карте. A доступен через `data-palette-variant="A"` на корневом элементе; снимки обоих вариантов сохранены рядом. B уменьшает число одновременно видимых подложек. Формула, значения и шкала оценки не меняются.
