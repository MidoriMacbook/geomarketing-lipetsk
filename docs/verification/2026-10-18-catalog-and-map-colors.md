## Реализация

- Дома — #91A5B8 с непрозрачностью .78; конкуренты — #B94F7B с непрозрачностью 1
  и светлой обводкой. Легенда использует те же токены. Остальные цвета,
  размеры маркеров, центроиды и оценки не менялись.
- Добавлены семь областей радиусом 1000 m с подтверждёнными жилыми ориентирами
  и пять типов бизнеса с точными OSM-фильтрами. Параметры из спецификации
  обозначены как эвристики. Меню получает каталог из API.
- Всего 110 снимков: 10 наборов домов и 100 наборов конкурентов.
  92 новых набора получены из реального OSM API 0.6, прежние 18 файлов
  сохранены побайтно. Источники покрывают радиус 1900 m. Центр собран
  из двух полных половин из-за лимита 50 тыс. узлов; нужная геометрия полная.
- catalog-provenance.json связывает 110 файлов с ключами, координатами,
  датами и хешами, 10 исходниками и 11 частями HTTP-загрузки.
  Источник и ODbL сохранены. Недоступные исходные URL и хеши прежних
  18 файлов указаны как историческое ограничение.
- Импортер проверяет XML, ошибки, структуру, повторные ID и теги, покрытие
  и геометрию. Поддерживается UTF-8; пределы — 64 MiB, 250 тыс. объектов,
  глубина 16, 1 млн раскрытых узлов. Все выбранные наборы проверяются
  до замены; атомарная запись выполняется отдельно для каждого файла.
- В меню из 10 строк при тексте 200% последняя строка обрезалась на 0.265625 px.
  Запас прокрутки 1 px устранил ошибку без прокрутки страницы.

## Границы

OSM может не содержать действующих конкурентов; нулевое число объектов
не доказывает отсутствие бизнеса. Жители и параметры — модельные оценки,
круги не являются административными границами. Физические телефоны, другие
браузерные движки, экранные дикторы и системная пагинация PDF не проверялись.
Исходные XML остаются локально; браузерные проверки запускаются отдельно от CI.
Новых зависимостей и платных API нет.
