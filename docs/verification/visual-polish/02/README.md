# Аннотации схемы

Наклонная подпись удалена. В SVG добавлены непрозрачные плашки Cream с Golos Text, тонкими выносками Rosewood и точками: дома, радиус, место. На телефоне остаются дома и место. Плашки масштабируются со схемой; адаптивные размеры шрифта сохраняют не менее 12 px на экране. Midnight Lagoon на Cream даёт контраст выше 10:1.

Сначала раскрывается маршрут (650 мс), затем подписи с шагом 180 мс. CSS запускает появление с первого кадра, без позднего скрытия при загрузке React. При reduced-motion подписи сразу видны. Регрессия проверяет размер, непрозрачность, отсутствие пересечений и положение строки координат ниже иллюстрации на четырёх ширинах.

Регион расположен в строке координат: на широком экране по центру, на телефоне отдельной строкой рядом с «К исследованию», чтобы сохранить читаемый текст. Рисунок ограничен своей областью и не заходит на заголовок.
