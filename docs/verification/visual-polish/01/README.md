# Выделение заголовка

Общий цвет выделения: Rosewood с прозрачностью 23%, текст Midnight Lagoon. У заголовка line-height 0,96, увеличены промежутки до подписи и города. На телефоне название помещается целиком в одну строку и копируется как «ГеоМаркетинг», без переноса внутри слова. SplitText разбивает только слова и восстанавливает исходную разметку после появления.

Регрессия проверяет название, отсутствие горизонтального переполнения и зазоры более 5 px между границами выделения и соседними строками на 375, 768, 1440 и 1920 px. Снимки `before-*.png` и `after-*.png` сделаны с Ctrl+A. Снимки всего этапа используют один локальный smoke-сервер с контролируемыми данными; внешние тайлы отключены для воспроизводимости.
