# Карточки области

«≈» перенесён из подписи в число и отделён неразрывным пробелом. Формат сохраняется при повторе анимации: раньше replayCounter терял префикс и суффикс. Добавлена регрессия повторного нажатия.

Отступы: 24 px на широком экране, 20 px на планшете и телефоне. Цифры табличные. На телефоне одинаковые рамки у всех карточек; прежние first/last-child правила давали разные края и фон. Слева у первой карточки на десктопе был намеренно убран отступ, а в старой мобильной сетке оставалась особая рамка первого элемента; это наследование стилей, не графический артефакт.

При наличии hover карточка поднимается на 3 px, появляется общая тень, стрелка смещается вправо. На сенсорном экране движения от наведения/нажатия нет. Исходные снимки пересняты с кодом d144dd7 через перехват ресурсов браузером без checkout; панель результатов свёрнута, чтобы не закрывать показатели.
