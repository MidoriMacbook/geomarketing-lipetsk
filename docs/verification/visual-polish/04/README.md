# Курсив заголовка

От 900 px «Маркетинг» использует уже установленный локальный Playfair Display Italic и Rosewood #B46A72. «Гео» остаётся прямым Midnight Lagoon. До 900 px сохранено прямое начертание. Дополнительные шрифты и внешние запросы не нужны.

Просмотрены 1280, 1440 и 1920 px: курсив читается, буквы не перекрыты. Область схемы опущена на 24 px после обнаруженного пересечения её верхнего края с нижними метриками заголовка на 1280 px. Регрессия дополнительно проверяет границу 900 px, отсутствие переполнения и положение рисунка ниже букв. Отказ от курсива на отдельных десктопных ширинах не потребовался.
