# Мобильная панель результатов

До изменения: `2ab3bec`. Экран 375 × 667, локальный сервер smoke с фиксированными данными; внешние тайлы отключены одинаково до и после. Это проверка интерфейса, не качества расчёта.

## Причина

В `static/js/atlas-interactions.js` обработчик расчёта заранее устанавливал `half`:

```js
document.addEventListener('gm:analysis-rendered',()=>{setSnap('half');sync();});
window.addEventListener('scroll',()=>{if(!scrollFrame)scrollFrame=requestAnimationFrame(sync);},{passive:true});
```

В `sync()` проверка `rect.top < innerHeight * .75 && rect.bottom > header + 60` включала фиксированную панель при приближении к карте. Последующий `setSnap(snap)` сохранял уже установленное `half`. Исходный журнал подтверждает: наверху страницы состояние уже `half`, после одной прокрутки — `sheetActive=true`, без нажатий.

## Изменения

- После расчёта — только `peek`, полоса 72 px со сводкой. `half` открывается ручкой, жестом или пином, `full` — кнопкой или жестом/стрелкой вверх.
- IntersectionObserver карты управляет только видимостью: скрывает ниже 20%, возвращает выше 40%. Обработчика прокрутки, раскрывающего панель, больше нет. Отдельный индикатор чтения страницы сохранён.
- Панель постоянно находится вне потока на телефоне; появление не добавляет отступ в документ. Переход transform/opacity 280 мс; reduced-motion — только opacity 180 мс.
- В half/full и во время жеста фон фиксируется с сохранением позиции. Esc и закрытие возвращают исходную позицию; клавиатура и увеличенный шрифт сохраняют доступность.
- Карта 58svh: в проверке 386,86 px вместо 346,83 px, больше требуемых 55% экрана. Статус 36 px, слои — одна горизонтальная строка с полосой прокрутки. Выбранный радиус кадрируется над панелью.
- Исправлен порядок фиксации высоты карты при pointerdown: сначала измерение, затем включение временного CSS-режима. Ранее измерение в обратном порядке могло давать 0 px.
- Внутренняя прокрутка без полосы со стрелками, overscroll contain; ручка 68 px.

Серии `before-appear-*`, `after-appear-*`, `after-expand-*`, `after-hide-*`: цели 0/100/200/400 мс. Снимок браузера сам занимает время, поэтому реальные времена замеров сохранены в `before.json` и `after.json`; это не обещание точности кадра до миллисекунды.

CLS в сопоставимом локальном проходе: **до 0,000548; после 0**. Высота карты после исправления одинакова во всех кадрах, включая раскрытие. В half/full `scrollY=0` из-за фиксации body, при закрытии восстанавливается исходный offset; положение самой карты на экране не меняется.

Целевые регрессии `tests/smoke/sheet-scroll.spec.js`: 20 проходов через карту с плавной и мгновенной прокруткой, колебания в полосе гистерезиса, тап, touch-жест, пин, клавиши, сохранение положения страницы и высоты карты, повторный результат и reduced-motion. Старые smoke-сценарии теперь явно открывают полосу вместо ожидания автоматического half.

## Проверка на физическом телефоне

1. Открыть сайт, дождаться расчёта: страница остаётся наверху; возле карты появляется только полоса с числом мест.
2. Медленно пройти карту вниз/вверх, затем несколько раз быстро пролистнуть её: полоса скрывается и возвращается, но не раскрывается; на границе не дрожит.
3. Потянуть ручку вверх до «Места», затем до «Все» и вниз: фон и карта неподвижны, список прокручивается внутри панели; после закрытия страница остаётся на прежнем месте.
4. Нажать другой пин: открываются «Места», выбранная точка и её радиус находятся над панелью. Пролистнуть строку слоёв до четвёртого переключателя.
5. Включить уменьшение движения, повторить быстрое открытие/закрытие и прокрутку; проверить также с открытой/скрытой адресной строкой Safari/Chrome. Панель появляется затуханием без скачка страницы.

Физические iPhone Safari и Android Chrome проверяет владелец; эмуляция Chrome не заменяет проверку инерции и динамической адресной строки на этих устройствах.
