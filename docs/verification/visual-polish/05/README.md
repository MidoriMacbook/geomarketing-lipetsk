# Общая визуальная проверка

Унифицированы контуры фокуса (3 px, отступ 3 px), заливка выделения на тёмных кнопках, пустые состояния с контурной схемой и карточки загрузки. Убрана большая прямоугольная заглушка на десктопе. Шаблоны жителей и расстояний используют неразрывный пробел.

На 320 px с текстом 200% строка координат переполняла экран; теперь её элементы располагаются вертикально и переносятся. Регрессия проверяет 320/360/390/430/1440 px, обычный и увеличенный текст.

Мобильная загрузка теперь показана без насильственного раскрытия панели: до первого результата она не перекрывает карту. Ошибка и отсутствие мест открыты явно. На всех четырёх ширинах горизонтального переполнения нет (`after-states.json`).

Навигация к сохранённым местам проверена отдельным браузерным сценарием: раздел раскрывается, получает фокус, пункт меню становится текущим. Этот путь уже работал — код навигации не изменён.
