# Аудит интерфейса перед редизайном

12 октября2026. Проверены исходные index.html/workspace.css/workspace.js и
существующие скриншоты. Исходный функциональный браузерный сценарий запускается
перед переносом. Это улучшение действующего аналитического инструмента.

| Наблюдение | Последствие | Решение |
| --- | --- | --- |
| Панели, KPI и списки оформлены похожими белыми округлыми карточками | Уровни продукта плохо различаются | Тёплая поверхность управления, карта-полотно, отдельный рабочий список |
| Большая площадь карты обусловлена высотой соседних карточек | Карта может быть вытянутой, а рабочий экран длинным | Осмысленная высота карты и компактные карточки справа |
| Сохранение, координаты и OSM выглядят равнозначными действиями | Неясен следующий шаг | Основное действие сохранить; две вторичные ссылки |
| Вступление и подписи часто uppercase | Излишний визуальный шум | Редакционный заголовок и обычный регистр |
| Значения цветов/размеров повторяются, часть цветов в JS | Сложно последовательно менять стиль | Единые tokens и чтение цвета маркера из CSS |
| Один JS-файл совмещает сеть, карту, хранилище и отчёт | Риск регрессий при небольших правках | Восемь модулей и явный объект состояния |
| Проверка адаптивности ранее ограничена390px | Не подтверждены крайние и промежуточные ширины | 360,390,768,1024,1280,1440px и внутренняя прокрутка таблицы |

Сохраняются полезные существующие решения: доступные notices, retry тайлов,
local Leaflet, Web Locks, отмена устаревших запросов, печать и CSV с безопасным
экранированием. Декоративные анимации и сторонний UI-framework не нужны.
