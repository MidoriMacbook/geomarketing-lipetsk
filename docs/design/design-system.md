# Дизайн-система ГеоМаркетинга

Направление от 16 октября 2026: городская картография, редакционная аналитика
и рабочая панель управления. Карта — основной визуальный объект; первая
рекомендация выделена тёмной поверхностью.

## Цвет и поверхности

Единственный источник — static/css/tokens.css. Material ссылается на те же
переменные; функциональные цвета карты отделены от цвета главного действия.

| --- | --- |
| Минеральная страница / полотно | --color-page #f1eee6 / --color-surface #fbfaf6 |
| Настройки / сохранённые | #eae7df / #e4e0d7 |
| Графитовый текст / вторичный | #15191c / #586066 |

Лайм сопровождает выбор и активность. Зелёные зоны обозначают относительную
оценку модели. Выбор дополнительно отмечен номером, линией, галочкой и aria-pressed.

## Типографика и масштаб

Два локальных семейства: Unbounded для display, Golos Text для текста и управления.
Cyrillic/Latin WOFF2, font-display:swap, OFL-лицензии рядом с файлами; около142KB
шрифтов. Кириллические подмножества предзагружаются, внешнего font CDN нет.
Метрики используют tabular-nums, координаты — системный моноширинный шрифт;
третья гарнитура не скачивается.

Базовый текст16px, подписи от12px. Display clamp(2.25rem,3.7vw,3.8rem),
на мобильном clamp(1.75rem,7.4vw,2.6rem). KPI жителей крупнее остальных.
Радиусы контролов/панелей6/12px. Цели управления минимум44×44px.
Focus3px с отступом3px, на тёмной рекомендации лаймовый.

## Композиция

Шапка меняет поверхность после прокрутки. Intro задаёт характер, асимметричные
KPI показывают область. Desktop: настройки220px, растягивающаяся карта,
рекомендации290px. Настройки: «Область», «Бизнес», «Отображение».
Первое место тёмное, «Сохранить» — главное действие. Shortlist имеет отдельную
поверхность, сравнение — таблицу с внутренним скроллом.

До1200px рекомендации переходят под карту; до900px настройки двухколоночные,
до600px последовательные. Высота карты desktop/tablet/mobile660/560/420px.
Длинные подписи переносятся, в том числе при200% текста. Печать показывает отчёт.

## Движение

Токены fast140ms, base220ms, slow420ms, stagger75ms.
Standard cubic-bezier(.2,0,.2,1), emphasized cubic-bezier(.2,.8,.2,1),
spring cubic-bezier(.2,1.35,.4,1). CSS: intro/hover/press; WAAPI: ответ на действия.
Основные свойства transform/opacity.

| Событие | Обратная связь |
| --- | --- |
| Первый экран | Однократное появление заголовка, подписи и действий |
| Карта и слои | Opacity полотна/pane, без изменения Leaflet transform |
| Реальный запрос | Indeterminate Material progress, без придуманных процентов |
| KPI | Конечное число записано сразу, затем короткое появление |
| Новый анализ | Рекомендации0/75/150ms только при новом analysis_id |
| Выбор места | Выделение карточки, один pulse внутреннего pin при смене rank |
| Hover/press | Цвет/граница и нажатие без изменения раскладки |
| Сохранение | Feedback после успешной записи, появление карточки |
| Удаление/сравнение | Выход копии, FLIP соседей, появление/обновление таблицы |
| Диалог | Вход/выход при немедленном native focus/Escape |
| Уведомления | Локальное появление рядом с причиной |
| Своя область | Переход с немедленным hidden/aria-expanded |
| Пустой результат | Спокойная смена состояния |

При reduced-motion эффекты отключены, включая runtime смену preference.
Ожидание остаётся видимым статическим индикатором. Финальные DOM/ARIA и данные
не ждут окончания эффекта. Непрерывного декоративного движения нет.

## Проверка

Цели: текст4.5:1, значимые границы контролов3:1. Focused browser QA измеряет
computed цвета, цели44px,390/768/1440,200% текста, native dialog, reduced-motion
и print CSS. Полный WCAG-аудит, native browser zoom и пагинация PDF не подтверждены.
UI/UX Pro Max использован для reduced-motion и Focus Not Obscured Minimum(AA);
Enhanced относится кAAA и не объявляется обязательным AA.
