# Дизайн-система ГеоМаркетинга

Актуальное направление от 17 октября 2026: тёмная городская аналитика,
палитра с присланного пользователем изображения: тёмный сливовый и пыльно-розовый.
Карта остаётся главным объектом. После обратной связи о сливающихся цветах
настройки перенесены на пудровую панель с тёмным текстом; KPI, рекомендации
и сохранения отделены собственными поверхностями, границами и заголовками.

## Палитра

Мягкие статические световые поля и картографическая сетка дают глубину первому
экрану. Карточки различаются плотностью и выделением, hover слегка приподнимает
их и подсвечивает границу. Цвет сопровождается номером, линией и aria-pressed.
Подложка OSM тонально обработана только в tile pane, canvas/маркеры/управление
не фильтруются. Атрибуция сохраняется; новый внешний провайдер не добавлен.
По обратной связи яркие голубой/коралл/золото заменены насыщенной пыльной розой,
ягодным и светлым лиловым. Дома непрозрачнее (.95), конкуренты имеют светлую
розовую обводку, скопления — светлые пунктирные кольца, рекомендации — номера.
Легенда повторяет формы. Общий --color-settings остаётся тёмным для прежних
кнопок; светлая панель использует отдельный --color-settings-panel и локальные
семантические токены. Выделение текста имеет собственные токены в обоих режимах.

## Типографика и композиция

Локальные Unbounded/Golos Text с кириллицей, WOFF2/OFL, font-display:swap.
Координаты — системный monospace; числа tabular-nums. Новых шрифтов нет.
Display заголовок набран светлым розовым. В intro есть переход к карте.

Прежняя рабочая сетка сохранена: 220 px настройки, растягивающаяся карта,
330 px рекомендации. До 1200 px рекомендации ниже карты, до 900 px настройки
двухколоночные, до 600 px последовательные. Карта 660/560/420 px.
Кнопки минимум 44×44 px, pressed использует сдвиг без уменьшения hit target.
Длинные подписи и метрики переносятся при 200% текста.
На ширине<=900px padding панели рекомендаций16px сохраняется; на телефоне
внутренние отступы кнопок карточек/select12px, tooltip8px по вертикали/12px сбоку.

## Движение, которое видно

Причина прежней незаметности: входы мобильных рекомендаций запускались на y≈2300,
до просмотра. Теперь reveal ждёт попадания блока в viewport через IntersectionObserver.
Контент всё время доступен: нет исходной CSS opacity0 или скрытия ради JS.
При отсутствии Observer вход выполняется сразу, работа интерфейса не блокируется.

Fast 220 ms, base 360 ms, slow 700 ms, intro 900 ms; stagger 75 ms.
Главный заголовок при первом открытии вкладки появляется по буквам с шагом38ms.
Session flag отключает повтор при reload; без storage — один раз на загрузку.
Полный доступный заголовок и его геометрия готовы сразу; reduce/print/hidden
восстанавливают исходные текстовые узлы. Остальные intro-входы сохраняются.
Более длительный вход выбран по прямому запросу пользователя на заметное движение;
данные, focus и действия не ждут его окончания.

| Событие | Эффект |
| --- | --- |
| Первый экран | Плавное появление текста и акцентной строки, световая композиция |
| Прокрутка | Вход настроек, карты, shortlist и карточек при просмотре |
| Расчёт | Настоящий Material indeterminate, без фиктивного процента |
| KPI и метрики/score | Точный текст сразу, визуальный count-up1100ms; refresh от прежнего значения |
| Новый анализ | Вход карточек только для нового analysis_id, stagger 0/75/150 ms |
| Выбор | Выделение карточки и pulse внутреннего pin |
| Hover / press | Подъём, световая граница, короткий сдвиг без потери размера |
| Сохранение / удаление | Feedback после записи, вход, выход копии и FLIP соседей |
| Сравнение / диалог | Вход/выход при немедленном DOM/ARIA/focus |
| Notices / своя область / empty | Локальные переходы при фактической смене состояния |

Runtime reduced-motion отменяет и активные, и ожидающие входы. Новое построение
карточек и reset фильтров очищают старые эффекты. Копии inert, без id/testid,
удаляются при finish/cancel/print. Нет scroll hijacking, per-point motion или
бесконечного декоративного pulse. Печать получает отдельную светлую палитру.

## Приёмка

Computed contrast, targets, 390/768/1440, 200% текста, keyboard/Escape, print CSS,
initial/runtime reduced-motion и viewport-entry проверяются браузерными сценариями.
Это не полный WCAG-аудит и не проверка всех browser engines/native PDF.
Новый tests/browser/dark-motion.js использует disposable page, не оставляя
instrumentation в рабочей QA-вкладке.
