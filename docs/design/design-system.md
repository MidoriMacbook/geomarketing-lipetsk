# Дизайн-система ГеоМаркетинга

Согласованное направление: urban-tech / editorial analytics; карта — основной
объект. Базовый бренд сохраняется, значения централизуются в tokens.css.

| Роль | Решение |
| --- | --- |
| Фон | Тёплый почти белый, без фонового декоративного градиента |
| Основной | Глубокий хвойный зелёный; высокая читаемость на светлой поверхности |
| Акцент | Один лаймовый для первой рекомендации, номера и небольших деталей |
| Поверхности | Страница, тонированные настройки, карта-полотно, рабочий список |
| Типографика | Onest/system sans для управления; Georgia/system serif, вес 700, для главного заголовка |
| Числа | tabular-nums, устойчивые поля для KPI, расстояний и score |
| Радиусы | Небольшая шкала, кнопки и панели различаются по уровню |
| Тени | Слабая функциональная тень только у приподнятых элементов/контролов |
| Состояния | hover, focus-visible, pressed, loading, error, empty, selected, saved |
| Движение | Короткая обратная связь, reduced-motion; никаких декоративных обязательных анимаций |

Обычный текст — 16 px, вспомогательный — не меньше 12 px.
Целевой контраст обычного текста 4.5:1, значимых нетекстовых контролов 3:1.
Кнопки/ссылки действий и touch-targets минимум 44 px; видимый focus.
Векторы и одинаковая толщина линий, декоративные SVG aria-hidden.

UI/UX Pro Max использован для проверки keyboard focus и доступности:
`python <skill>/scripts/search.py "keyboard focus data table" --domain ux -n2 --json`.
Полученная рекомендация Focus States подходит формам/диалогу; Focus Not Obscured
Enhanced относится кAAA и не объявляется обязательным AA-требованием.
Палитра из поискового каталога не заменяет согласованные пользователем цвета.

## Основные токены

Единственный источник значений — `static/css/tokens.css`; JS карты читает
семантическую палитру один раз на перерисовку.

| Токен | Значение / применение |
| --- | --- |
| `--color-page`, `--color-surface` | `#f6f5ee`, `#fffef9`: страница и полотно |
| `--color-settings`, `--color-saved` | `#e9eee4`, `#e5e9df`: разные рабочие поверхности |
| `--color-ink`, `--color-primary` | `#143d30`, `#163f32`: текст и главное действие |
| `--color-accent`, `--color-featured` | `#d1e97c`, `#f1f5dd`: номер и первая рекомендация |
| `--radius-control`, `--radius-panel` | 5 px, 8 px |
| `--size-target` | 44 px, обе стороны интерактивной цели |
| `--size-map-desktop/tablet/mobile` | 660 / 560 / 420 px |
| `--size-table` | 760 px, прокрутка внутри контейнера |
| `--size-kpi-min` | 8rem: минимум мобильного KPI, естественный перенос при большом тексте |
| `--text-title`, `--text-title-mobile` | clamp(2.3rem, 4.2vw, 4.2rem), 2.6rem |
| `--focus-width`, `--focus-offset` | 3 px, 3 px |
| `--z-map`, `--z-zones`, `--z-points`, `--z-skip` | 0 / 405 / 420 / 2000 |

Проверены 360, 390, 768, 1024, 1280 и 1440 px: горизонтального переполнения нет,
кнопки действий не обрезают текст и имеют размер не менее 44×44 px.
Клавиатура прокручивает сравнение внутри таблицы; диалог возвращает focus.
Print CSS и reduced-motion проверены браузером. Полный аудит WCAG не выполнялся.

При увеличении root font-size до 200% проверены 360/390/1024/1280 px,
сохранённые карточки и сравнение: нет переполнения страницы или обрезанных действий.
Computed contrast Save: hover 8.04:1, обычный focus 11.60:1,
saved hover/focus 9.95:1. Это проверки конкретных состояний, не полный WCAG-аудит.
