# Дизайн-система ГеоМаркетинга

Актуально 22 октября 2026: светлая городская аналитика по подробному заданию
пользователя. Крупная editorial-обложка продолжена строгой рабочей картой.
Референсы задают типографику, асимметрию и воздух; фотографии и цветы не копируются.

## Цвета и уровни токенов

Единственный источник CSS-цветов — static/css/tokens.css. Примитивы palette
переходят в семантические color-токены, затем в локальные роли панелей/Material.

| Примитив | Значение | Роль |
| --- | --- | --- |
| Vanilla Cream | #FFF7E6 | Фон страницы и hero |
| Blush Petal | #F7C8D3 | Выделение, светлые акценты на карте |
| Rosewood | #B46A72 | Конкуренты и декоративный маршрут |
| Sage Leaf | #A8B58A | Центроиды и семейство зон спроса |
| Misty Sky | #A9B7C6 | Дома и кварталы схемы |

| White | #FFFFFF | Настройки, рекомендации, сохранения, исследования |
| Rosewood Deep | #89434E | Доступный primary CTA и акцентный текст |
| Rosewood Hover | #71343F | Наведение на primary |
| Muted Ink | #596470 | Подписи и вспомогательные сведения |
| Border | #808890 | Граница контролов и фокус |

Blush не используется для обычного текста на светлой поверхности. Отдельные
error/notice/success роли имеют текстовые сообщения; цвет не заменяет смысл.
Выбранная рекомендация: светло-розовый фон, глубокий Rosewood-индикатор/номер.
Сравнение сохранений/исследований сохраняет отдельную inset-полосу.

Карта имеет независимые on-map роли: светлые подписи, тёмные контролы и tooltip,
контрастные обводки конкурентов, пунктирные кольца центроидов и номера мест.
Тональная обработка действует только на OSM tiles, canvas и маркеры не фильтруются.
Форма/размер дополняют цвет: дома с заливкой .78, конкуренты непрозрачны,
центроиды — кольца, рекомендации — номера, спрос — полупрозрачная площадь.

## Типографика и композиция

Локальный Playfair Display с кириллицей/латиницей, normal+italic variable400–900,
применяется в hero и редких крупных заголовках. Golos Text остаётся во всех
формах, карточках, таблицах и данных. Координаты/метки — системный monospace.
Числа tabular-nums. Лицензия OFL и происхождение шрифтов находятся рядом с WOFF2.

Headline имеет явный смысловой перенос, а не ширину в ch, меняющуюся при загрузке
шрифта. Это предотвращает скачок строк при font swap. Критический normal Cyrillic
preload, остальные подмножества/italic загружаются по необходимости; display swap.

Hero около485px на1440,430px на768,440px на390 при обычном размере текста.
На телефоне спокойная типографическая обложка сохраняет CTA; схема не конкурирует
с текстом. При200% высота растёт естественно. Нет фиксированного100vh/обрезки.
Схема подписана «Схема поиска»: она объясняет идею, не выдаёт декоративные точки
за данные модели. После неё сразу идут KPI и рабочая карта.

Навигация компактна и становится липкой после JS-инициализации. Без JS ссылки
видны в обычном потоке. При прокрутке меняются фон/тень/размер знака, не высота
резерва. Реальная высота измеряется ResizeObserver для якорей. Мобильное меню
считает доступную высоту экрана, прокручивается вертикально и доступно с клавиатуры.

Карта/рекомендации по-прежнему делят desktop-высоту от1024px с комфортным пределом.
На планшете/телефоне порядок настройки → карта → рекомендации. Данные перед footer;
пустые исследования скрыты, первое сохранение доступно после рабочей зоны.

## Движение и взаимодействия

React-island — отдельное улучшение статической обложки, не владелец приложения.
Источники React Bits и адаптации описаны в static/vendor/hero/SOURCES.md.

| Событие | Поведение |
| --- | --- |
| Hero h1 | SplitText: слова,16px,55ms stagger, один вход; исходный h1 сохраняется |
| Короткое описание | BlurText: мягкий blur≤4px → sharp, затем очистка inline styles |
| Прокрутка | ScrollReveal: только5блоков KPI/workspace/saved/research/data, один раз |
| Указатель в hero | Fine hover, сдвиг SVG-групп≤6px, RAF только при событии |
| KPI | Существующий точный count-up, без второго счётчика или изменения CSV |
| Hover карточек | Подъём и подсветка; выбранная рекомендация остаётся устойчивой |
| Сохранение/удаление | Отклик только после записи, exit/FLIP без задержки данных |
| Выбор места | Краткий pulse внутреннего pin, без движения координатной обёртки |
| Details/меню | Прерываемый переход при немедленных DOM/ARIA/focus состояниях |
| Расчёт | Настоящий Material indeterminate и честный статус, без вымышленного процента |

Нет per-row entrances, typewriter, trails, WebGL, scroll hijacking или бесконечных
пульсаций. Reduced motion/print завершают активные эффекты, снимают split/blur/drift
и оставляют полную информацию. Уход hero за экран, blur/visibility также сбрасывает
cursor-движение. Отказ острова оставляет обычную статическую страницу.

## Доступность и проверка

Текст AA≥4.5:1, крупный текст/границы и фокус≥3:1, targets≥44px. Контраст проверяется
на настоящих rendered состояниях, включая selected/hover/pressed, а не только токенах.
Сохранённые кнопки переключают контрастную пару текста/фона атомарно, сохраняя
transform/shadow feedback: промежуточный crossfade не должен ухудшать читаемость.
Печать использует отдельный светлый DOM и не зависит от экранных раскрытий.
Обязательны390/768/1024/1440,200%, short landscape, noJS, keyboard/Escape,
initial/runtime reduce, delayed/failed island, CLS и старые функциональные сценарии.
