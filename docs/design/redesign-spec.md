# Спецификация редизайна

Текущая итерация16октября2026 выполняет пользовательский brief: выразительная
городская картография, редакционная аналитика и панель управления.
Подробные требования: docs/specs/2026-10-16-cartography-motion-design.md.
План: docs/plans/2026-10-16-cartography-motion.md.

## Результат

Минеральная страница, графитовый текст, терракотовое действие, локальные тёмные
поверхности и лаймовый сигнал выбора. Unbounded/Golos Text локальны с кириллицей.
Реальная карта остаётся главным визуальным объектом.

Шапка компактная; intro объясняет продукт; KPI асимметричны. Настройки разделены
на область, бизнес и отображение. Desktop-карта шире обеих боковых панелей.
Первая рекомендация тёмная, сохранение выделено. Shortlist/сравнение — отдельный
рабочий этап. Все разделы адаптируются к390/768/1440px.

CSS/WAAPI сопровождают intro, карту/слои, ожидание, KPI, новые рекомендации,
выбор, нажатия, сохранение, удаление/сравнение, диалог, notices, свою область
и пустое состояние. Stagger75ms только для нового analysis_id; pulse при смене rank.
Отмена не меняет финальные DOM/ARIA, focus, storage или requestVersion.
Reduced-motion работает при старте и runtime смене, включая Material shadow.

## Совместимость

Стек Flask/HTML/CSS/JS/Leaflet сохраняется. Без React/Tailwind/shadcn/GSAP/Framer
или смены модели. API/JSON/snapshots/storagev1/CSV/print и прежние id/testid/имена
сохранены. Пять категорий, три района, своя область, слои, три рекомендации,
12 сохранений и сравнение до трёх доступны.

Material используется для настоящего ожидания; native controls сохранены.
Отказ vendor не блокирует приложение. Временные копии inert/aria-hidden,
без id/testid, не попадают в печать и хранение.

## Приёмка

Один итоговый набор: check:material,51unittest,validate_project.py,синтаксис JS.
Один QA-сеанс: прежний workspace.js и новый redesign.js покрывают разные риски.
Все старые матрицы без причины не повторяются; при ошибке повторяется затронутая
проверка. Parent лично просматривает финальные390/768/1440.
Контраст4.5:1/3:1,цели44px,keyboard/Escape,200% текста,runtime reduced-motion,
print CSS и отказ Material проверяются.

Независимые task-review/whole-branch review до публикации. После зелёного CI
обновляется существующий бесплатный Render; публично проверяются новые assets
и расчёт. Полный WCAG, все движки, native PDF и полнота OSM не заявляются.
