# Спецификация редизайна

## Текущая итерация: рабочая зона и проверка на месте

Спецификация19октября2026:
docs/specs/2026-10-19-workspace-flow-and-field-checks.md.
Сливовый фон, пудровые настройки, серо-синие дома и ягодные конкуренты сохранены.
На desktop карта растягивается рядом с рекомендациями: flex распределяет
свободную высоту, а ResizeObserver сообщает Leaflet новый размер без сброса
выбора. Минимум защищает пустую карту, комфортный предел ограничивает длинные
раскрытия. При пределе прокручивается результат. Мобильный порядок:
настройки → карта → рекомендации.

Краткий статус источника и свежести остаётся у карты. «Проверить детали»
открывает нижний раздел «Данные и ограничения расчёта» перед footer,
после сохранённых мест, сравнения и исследований. На экране details закрыт;
печатный отчёт содержит все сведения независимо от экранного состояния.

«Почему это место» объясняет спрос относительно текущего анализа, жителей
в радиусе, конкуренцию и ближайшего конкурента, реальные причины и проверки.
Модель не обещает выручку. У сохранённой точки есть отдельная сворачиваемая
«Проверка пользователя»: семь локальных отметок о помещении и окружении,
без влияния на score/API. Ключ field-checks.v1 отделён от saved.v1.

Полные сценарии уже реализованы: в UI они называются «Исследования».
Раздел появляется после первой записи либо при проблеме хранилища, когда
нужно восстановление. Первое сохранение доступно вне скрытого раздела.
Исследование сохраняет район, тип бизнеса и результаты для сравнения позже;
оно отличается от отдельного сохранённого места.

Hover связывает карточку с маркером; выбранная карточка устойчива. Добавлены
прерываемые раскрытия, feedback кнопок, однократные входы панелей в viewport.
Смена слоя не повторяет entrance. Reduced motion завершает текущие эффекты
и отключает reveal/lift/pulse. Count-up, клавиатура, focus и ARIA сохраняются.

Контракты: каталог10×10, custom area, API/JSON, saved.v1/scenarios.v1, прежние
ids/testids, CSV/print, Leaflet/Material без новых зависимостей. Приёмка:
1440/1024/768/390px и200% текста,0/1/3 карточки, раскрытие/выбор/размер карты,
keyboard/touch, хранилище/две вкладки/ошибки, обновление данных, reduce/print.
Доказательства: docs/verification/2026-10-19-workspace-flow-and-field-checks.md.

## Внешний вид

Тёмный графитовый фон и поверхности, светлая типографика, бирюзовые действия,
мягкое свечение и картографическая сетка. Unbounded/Golos Text остаются локальными.
Карта с тёмной монохромной подложкой; функциональные слои не фильтруются.
Настройки/рекомендации/shortlist адаптируются как в прежнем рабочем интерфейсе.
Светлый печатный отчёт отделён от оформления экрана.

## Движение

Входы секций и результатов выполняются при попадании в viewport, чтобы не
заканчиваться до просмотра. Начальная CSS opacity не скрывает контент.
Вход 700 ms, intro 900 ms, действия 220–360 ms, stagger 75 ms.
Новый analysis_id запускает новый набор; выбор места не повторяет stagger.
Очередь очищается при отмене, reset, перестроении и reduced-motion.
DOM/ARIA/focus и запись данных не ждут анимации. CSS/WAAPI, без новых библиотек.

## Совместимость

Flask/HTML/CSS/JS/Leaflet, API/JSON, модель, snapshots, storage v1, Web Locks,
CSV/print, native controls и прежние id/testid/имена сохранены.
Пять категорий, три готовых района и своя область, слои, до трёх рекомендаций,
12 сохранений, сравнение до трёх остаются доступными.

Material Web реально используется для ожидания; отказ vendor оставляет div
fallback и работающий интерфейс. Reduced-motion учитывается при старте/runtime,
включая ShadowRoot Material. Финальные данные доступны без IntersectionObserver.

## Проверка

Прицельный dark-motion RED до реализации, затем GREEN; workspace regression,
обновлённый focused redesign scenario, три ширины/200%/контраст/print/ошибки.
Parent лично просматривает финальные страницы и промежуточный кадр движения.
Независимое whole-branch review и CI до обновления main/Render, затем public smoke.
История предыдущего светлого редизайна остаётся в Git/CHANGELOG.
