# Визуальный редизайн: светлая карта города

Спецификация от22октября2026 с полировкой23октября2026 замещает прежнее сливово-розовое оформление
по прямому новому заданию пользователя. Полный контракт:
docs/specs/2026-10-22-editorial-map-hero.md.

## Первый экран

Компактная навигация и крупная асимметричная обложка — самостоятельные уровни.
Vanilla Cream, Playfair Display/Onest и тёмный Midnight Lagoon создают
читаемую editorial-композицию. Rosewood Deep выделяет CTA и слово «место».
SVG-кварталы/радиусы/маршрут иллюстрируют задачу и реагируют на точный указатель.
Это декоративная схема с подписью, без фальшивой статистики, фотографий и растений.

Статический h1 «У каждого бизнеса есть своё место» и описание доступны до React.
«Открыть карту» ведёт к рабочей зоне; «Как работает расчёт» открывает прежний
диалог модели. Печатный отчёт перенесён к действиям рабочей зоны, сохранив id.
Hero не становится отдельным рекламным лендингом: после него KPI и карта.

## Навигация и адаптация

JS включает sticky-поведение после установки доступных обработчиков. Высота
содержимого не прыгает при скролле; кремовый фон и геометрия сохраняются, scroll добавляет мягкую тень.
ResizeObserver обновляет отступ якорей по реальной высоте. Без JS header остаётся
в потоке: увеличенные подписи не перекрывают переходы.
До900px меню открывается кнопкой с aria-expanded/controls; закрывается Escape,
переходом, уходом фокуса/внешним кликом. Закрытое меню inert. Диалог из меню
возвращает фокус на доступную кнопку меню, hero-диалог — на свою кнопку.
Короткий экран с200% текста получает вертикальную прокрутку меню, а не колонки.

Desktop hero380–520px, mobileдо560px при стандартном тексте; при200% высота
растёт без обрезки. На телефоне схема заменена горизонтальной SVG-полосой70px.
Рабочие панели Warm Cream #FEF1E3, границы и номера разделяют их; serif не используется в данных.
Функционально тёмная карта имеет собственные легенду/подписи/tooltip/control roles.

## Motion ownership

Отдельный React-island монтирует effect-controller в пустой #hero-motion-root,
анимируя существующие DOM-узлы. Он не создаёт второй заголовок и не владеет
каталогом/формой/Leaflet/storage. Поставляется локальным Rollup-bundle.

Реальные исходники React Bits закреплены revision, hash и лицензиями. SplitText
адаптирован для external h1/words; BlurText для короткого static p; ScrollReveal
для пяти одноразовых block-entry вместо текстового scrub. Эти отличия описаны
в SOURCES.md. Существующие row/panel reveal отключены во избежание двойных входов,
но save/delete feedback, disclosures, marker pulse и точный count-up сохранены.

Весь контент виден при delay/failure/noJS; работающий JS готовит пять разделов к входу0→1/y24px. React не меняет textContent, смысл
или геометрию заголовка; временные word-wrappers снимаются. Reduced motion/print
останавливают активные и ожидающие эффекты; pointer reset выполняется при
leave/blur/offscreen/visibility. Событийный RAF останавливается после возврата Magnet; только SVG имеет медленные
CSS-циклы с паузой/viewport/visibility/reduce/print. Canvas/WebGL в hero нет.

## Сохранённая работа приложения

Каталог10×10/API/Flask/математика, общая высота карты/рекомендаций, Leaflet layers
и selection/resize, saved.v1/scenarios.v1/field-checks.v1, CSV/печать и ARIA/ids
остаются прежними. Исследование открывает архив на карте без нового запроса.
Подробные даты и ограничения — перед footer; краткий trust остаётся у карты.
Семь пользовательских отметок не влияют на расчёт и хранятся отдельным ключом.

## Приёмка и границы

Проверяются реальные initial/loading/error/results/saved, а не только первый экран.
Новая матрица включает noJS/200%/shortviewport, AA/targets/focus, fallback island,
фактические word/blur эффекты, pointer≤6px, initial/runtime reduce, print/CLS,
workspace/storage/scenarios/CSV и воспроизводимые Material+hero сборки.
Reactостров:316045raw/104413gzip bytes, бюджет≤180KiB gzip. Измерять полный и
добавленный островом CLS отдельно. Chrome/touch emulation не заменяет проверку
физических телефонов, других движков и native PDF-пагинации.

Точные новые значения, причины изменений и правила прерывания:
docs/specs/2026-10-23-warm-motion-polish.md. Основная CTA — Magnet, вторичная —
text-action с линией только под текстом. Белый допустим исключительно в печати.
