# Material Web и визуальный референс Skiper UI

## Используемый компонент

Локальная сборка `@material/web` версии 2.5.0 импортирует только
`md-linear-progress`. Элемент расположен в `#analysis-progress` и виден при
расчёте или обновлении. Неопределённое ожидание имеет доступное имя без
фиктивного процента; после завершения или отмены запроса полоса скрывается.

Нативные button/select/checkbox/range/dialog сохраняются: на их DOM API,
доступные имена, фокус и Escape опираются текущие сценарии. Неиспользуемые
регистрации удалены. Переменные `--md-*` ссылаются на общие токены цвета,
размера, формы и шрифта. Отдельной палитры Material нет; печатный отчёт
не содержит индикатор ожидания.

## Уменьшение движения и отказ сборки

CSS страницы не управляет Shadow DOM. При включённом уменьшении движения
`ui.js` снимает `indeterminate`, скрывает Material и отменяет его анимации
после обновления Lit. Вместо него показывается статический `.progress-fallback`.
Переключение настройки во время работы не требует перезагрузки. Проверка версии
операции не даёт запоздавшему обновлению вернуть отменённую анимацию.

Резервный div имеет `role=progressbar` и имя, без `aria-valuenow`. При отказе
сборки он показывает ожидание; API, карта и нативные элементы управления
продолжают работать. Бизнес-логика не ждёт `whenDefined`. После запроса оба
варианта индикатора скрываются.

## Сборка и проверка

Версии зафиксированы в package.json и pnpm-lock.yaml. Rollup и node-resolve
собирают `scripts/frontend/material-web-entry.js` в
`static/vendor/material-web/material-components.js`. Карта исходников не публикуется.

```powershell
pnpm install --frozen-lockfile
pnpm run check:material
```

Проверка пересобирает файл; отдельно запускать build:material после неё не нужно.
Готовая сборка включена в Git, для запуска Python/Render Node.js не требуется.
CI использует Node 24 и pnpm 11.25.0, проверяет воспроизводимость и синтаксис JavaScript.

## Skiper UI и дальнейшие компоненты

Skiper UI использовался как визуальный референс компактной навигации,
типографики и коротких взаимодействий. Он не установлен, платные компоненты
и исходники не копируются. React/TSX/shadcn/Tailwind не являются обязательными
зависимостями основного интерфейса; его анимации используют CSS и WAAPI.

Перед добавлением нового Material-контрола нужно описать пользу и нативные
контракты, добавить один импорт, сопоставить токены и проверить клавиатуру,
фокус, области нажатия 44px, мобильный экран, уменьшение движения и отказ сборки.
`tests/browser/material-web.js` проверяет готовый DOM, `redesign.js` — индикатор
при запросе и оба резервных сценария.
