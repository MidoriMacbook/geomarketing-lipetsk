# Полировка мобильных взаимодействий — 27 октября 2026

Основание: подробное задание пользователя после мобильного выпуска `913b5f8`.
База Git `568fb42`. Палитра, шрифты, карта первой, единственная форма в нижней
панели, две основные метрики и первая раскрытая рекомендация сохраняются.

- Рекомендации: управляемое раскрытие через CSS Grid, прозрачность и transform;
  закрытие быстрее открытия, скрытое содержимое inert, фокус возвращается в строку.
  Повторное нажатие меняет направление перехода. Выбор строки не прокручивает карту.
- Панель: вход до 300ms, выход 220ms, затемнение и декоративный хвататель.
  Кнопка после результата называется «Изменить параметры»; резюме и ошибка ясны.
  Клавиатура, модальность и успешный явный запуск сохраняют прежние контракты.
- KPI: короткая волна от точки нажатия либо центра при клавиатурном действии;
  подпись активного действия и прежняя связь со слоями без изменения данных.
- Расчёт: один основной индикатор ожидания и статичный компактный skeleton
  рекомендаций. Запуск блокируется, подпись мгновенно меняется. Предыдущий успешный
  расчёт остаётся доступным с собственным контекстом, включая ошибку новых параметров.
  Форма сохраняет новые параметры для повторной попытки; архив и отчёт используют
  контекст показанного расчёта. Устаревший ответ не заменяет новый результат.
- Успех: сначала KPI, затем одноразовое появление карточек с шагом50ms.
  Сохранение подтверждается только после записи; место под сообщение зарезервировано.
- Уменьшение движения, печать и смена размера завершают переходы. Новых эффектов
  обычной прокрутки, жестов панели, библиотек и постоянного pulse нет.

API, сервер, модель, Leaflet, форматы и ключи хранения, CSV и печать не меняются.
Приёмка:320×568,390×844,430×932,844×390 с касаниями,768×1024,1280×900,
текст200%, клавиатура, быстрые повторы, успех/ошибка/повтор, выбор и сохранение.
