# ГеоМаркетинг: городская картография и анимации

Основание: подробное задание пользователя от 16 октября 2026.
Это историческая спецификация композиции, картографической палитры и анимаций.

## Аудит до изменений

Приложение запущено на localhost:5083. Исходные 390/768/1440 px просмотрены
в браузере и на снимках tests/artifacts/urban-before-{width}.png.
Переполнения нет, высота карты 420/560/660 px. Сборка Material Web готова,
но md-компонентов в рабочем интерфейсе нет. После загрузки активных анимаций 0.

Проблемы: зелёно-бежевые поверхности близки по тону; четыре KPI равноправны;
небольшие одинаковые карточки/рамки ослабляют иерархию; заголовок Georgia
не связан с современной картографией; большой планшетный блок настроек
отодвигает карту; загрузка и смена результатов почти не имеют обратной связи.
Сохранить: информационный порядок, нативное управление, доступность, обработку
отказов, локальный Leaflet, Web Locks и все контракты.

Визуальный ориентир — Skiper UI: https://skiper-ui.com. Используются характер
коротких ответных движений, компактная навигация и чёткие состояния нажатия и наведения.
Исходники и компоненты сайта не копируются.

## Визуальное направление

Городская картография, редакционная подача аналитики и компактная панель управления:
выразительное рабочее пространство с большой реальной картой и умеренной анимацией.

Минеральный фон #f1eee6, поверхность #fbfaf6, графит #15191c, тёмный
модуль #172126. Основной терракотовый акцент #bf492d, наведение #a63c25, светлый текст.
Лайм #d9f45b только для выбранного/активного. Функциональные цвета карты
отдельны: дома приглушённые сине-серые, конкуренты сливовые, зоны зелёные.
Контраст текста с фоном проверяется на 4.5:1, значимых границ элементов управления — на 3:1.

Выразительный Unbounded с кириллицей для главного заголовка, Golos Text для интерфейса;
цифры равной ширины, координаты системным моноширинным шрифтом. Не более двух загружаемых семейств;
локальные WOFF2 с font-display:swap и лицензиями, системный резерв при отказе.
Если источник шрифта недоступен, использовать проверенный системный резерв
и явно зафиксировать фактический вариант. Никакого ожидания шрифта для запуска API.

Существующая семантическая система tokens.css развивается: никакого второго
источника палитры. Токены размеров, радиусов, теней, z-index и анимации общие.
Material --md-* ссылаются на эти же значения.

## Композиция и DOM

Компактная шапка, ясная активная навигация, наблюдение за контрольным элементом
через IntersectionObserver для класса is-scrolled. Закрепление при прокрутке допустимо,
если оно не перекрывает фокус; на узком экране шапка обычная. Крупный заголовок,
короткое описание, город, вторичное действие печати отчёта. KPI как аналитическая лента:
население имеет больший вес, категория/район доступны рядом.

На компьютере: настройки около 220 px, рекомендации около 290 px, карта самая широкая.
На планшете: настройки и карта без узких колонок, рекомендации ниже. На телефоне:
вступление → KPI → настройки → карта → рекомендации → сохранения, без переполнения страницы.
Карта высотой минимум 420 px. При 200% текста естественный перенос, без обрезки через overflow:hidden.
Сравнение прокручивается внутри контейнера, заголовки таблицы читаемы.

Стабильные точки подключения:

- #header-sentinel, .site-header.is-scrolled;
- #analysis-context рядом с KPI, #analysis-status в контрастной полосе карты;
- #analysis-progress с md-linear-progress и .progress-fallback;
- html[data-analysis-state] initial/calculating/refreshing/success/error.

Структурная проверка нового интерфейса контролирует наличие этих элементов и состояний.

Нативные button/select/checkbox/range/dialog сохранены: JavaScript читает value,
selectedOptions, checked, disabled и использует showModal/close. Реальный
Material-компонент — md-linear-progress во время расчёта. Он не требует
адаптера ввода. Остальные элементы Material Web не заменяют нативные автоматически.
Точка сборки включает только используемый индикатор; локальная сборка воспроизводится.
При отказе сборки остаётся нативный индикатор progress; API и настройки работают.

## Анимации

Все состояния сначала устанавливают конечный DOM/ARIA, движение вторично.
Токены: fast 140 мс, base 220 мс, slow 420 мс, последовательная задержка 75 мс;
собственная кривая cubic-bezier. Без GSAP/Framer, перехвата прокрутки,
постоянных пульсаций и перерасчёта раскладки на каждом кадре.
CSS keyframes для первого появления; Web Animations API для ответов на события.

1. Первый экран: короткое появление типографики, без длительной блокировки.
2. Карта: появление после инициализации Leaflet; непрозрачность меняется у целого слоя,
   transform контейнера Leaflet не затрагивается. При отказе тайлов работает прежний резервный режим.
3. Загрузка: индикатор неопределённого ожидания работает только во время запроса.
   Обновление сохраняет предыдущий результат; первый расчёт показывает спокойный каркас загрузки.
4. KPI: конечные числа выставляются сразу; появление короткое, через opacity/translate.
5. Новые рекомендации: задержки 0/75/150 мс только для нового analysis_id.
6. Выбор: изменение карточки и короткая пульсация внутреннего маркера, без изменения
   transform координатной обёртки Leaflet. Повтор того же ранга не перезапускает эффект.
7. Кнопки: наведение и нажатие дают отклик, сохраняя раскладку и доступную область.
8. Сохранение: обратная связь только после успешной записи; новая карточка плавно появляется.
9. Удаление, сравнение, пустые состояния: короткое исчезновение снимка и FLIP соседей,
   без задержки изменения хранилища и скрытых интерактивных дублей.
10. Диалог: появление и исчезновение; Escape работает нативно, фокус и видимость меняются немедленно.
    Анимация не задерживает close. При необходимости исчезает неинтерактивный снимок с inert.
11. Сообщения в потоке страницы: короткое появление текста без перехвата фокуса.
12. Своя область: мягкое раскрытие и скрытие без задержки актуальных hidden/ARIA.

Программные Animation.id имеют префикс gm: для диагностики фактических эффектов.
При новых событиях прежний эффект элемента отменяется; отклонение finished обработано.
При переключении prefers-reduced-motion все активные эффекты отменяются,
CSS-анимации выключены. Неопределённый индикатор Material Web останавливается, видна статичная
семантическая индикация ожидания без выдуманного процента. Нет зависимости
корректности от animationend/finished. В печати нет движения и временных снимков.

## Контракты и риски

Сохраняются сервер, API, JSON, модель, geomarketing.saved.v1, CSV, печать,
id/data-testid, доступные имена, отмена запросов, хранилища и Web Locks.
Направление этапа: светлая тема с локальной тёмной аналитической поверхностью,
без React/Tailwind, декоративной обложки и принудительного тёмного режима.
Основной визуальный материал — реальная карта; композиция подчёркивает её роль.

Критические сбои: устаревший запрос перезапускает загрузку; анимация удерживает
hidden или фокус; временные дубли вмешиваются в селекторы и хранилище.
Защита: существующий requestVersion, немедленное конечное состояние DOM,
снимки с inert/aria-hidden без id/data-testid и их очистка при завершении или отмене.
Уменьшение движения проверяется при старте и при смене настройки во время работы.

## Проверка и публикация

Серверные проверки: pnpm run check:material, unittest и проверка структуры.
Браузерные проверки включают прежние сценарии рабочего пространства и риски редизайна:
анимации, загрузку, обновление, ошибку, уменьшение движения и резервный режим.
Проверяются ширины 390/768/1440 px, 200% текста, контраст, области нажатия,
сохранения, сравнение, диалог и печать; pageErrors=[] и итоговые снимки каждой ширины.
После проверки реализации и GitHub Actions обновляется существующий бесплатный Render;
сверяются публичные health/API, статические файлы и внешний вид.
