# ГеоМаркетинг: городская картография и motion

Основание: подробное задание пользователя от 16 октября 2026. Пользователь
прямо поручил реализацию до законченного состояния; повторное согласование
палитры, этапов или начала работ не требуется.

## Аудит до изменений

Приложение запущено на localhost:5083. Исходные 390/768/1440 px просмотрены
в браузере и на снимках tests/artifacts/urban-before-{width}.png.
Переполнения нет, высота карты 420/560/660 px. Material bundle ready,
но md-компонентов в рабочем интерфейсе нет. После загрузки активных анимаций 0.

Проблемы: зелёно-бежевые поверхности близки по тону; четыре KPI равноправны;
небольшие одинаковые карточки/рамки ослабляют иерархию; заголовок Georgia
не связан с современной картографией; большой планшетный блок настроек
отодвигает карту; загрузка и смена результатов почти не имеют обратной связи.
Сохранить: информационный порядок, native controls, доступность, обработку
отказов, локальный Leaflet, Web Locks и все контракты.

Skiper UI открыт и просмотрен: https://skiper-ui.com. Используются характер
коротких ответных движений, компактная навигация и тщательные press/hover.
Исходники и компоненты сайта не копируются.

## Art direction

Urban cartography × editorial analytics × modern control room.
DESIGN_VARIANCE 6, MOTION_INTENSITY 5, VISUAL_DENSITY 6: выразительное рабочее
пространство с большой реальной картой, а не маркетинговая страница.

Минеральный фон #f1eee6, поверхность #fbfaf6, графит #15191c, тёмный
модуль #172126. Терракотовый primary #bf492d, hover #a63c25, светлый текст.
Лайм #d9f45b только для выбранного/активного. Функциональные цвета карты
отдельны: дома приглушённые сине-серые, конкуренты сливовые, зоны зелёные.
Пары текста проверяются на 4.5:1, значимые границы контролов на 3:1.

Выразительный Unbounded (Cyrillic) для главного заголовка, Golos Text для UI;
цифры tabular, координаты системные mono. Не более двух загружаемых семейств;
локальные WOFF2 с font-display:swap и лицензиями, системный резерв при отказе.
Если источник шрифта недоступен, использовать проверенный системный резерв
и явно зафиксировать фактический вариант. Никакого ожидания шрифта для запуска API.

Существующая семантическая система tokens.css развивается: никакого второго
источника палитры. Токены размеров, радиусов, теней, z-index и motion общие.
Material --md-* ссылаются на эти же значения.

## Композиция и DOM

Компактный header, ясная активная навигация, наблюдение sentinel через
IntersectionObserver для is-scrolled. Sticky допустим только при безопасном
фокусе; на узком экране header обычный. Крупный display-заголовок, короткое
описание, город, вторичный печатный отчёт. KPI как аналитическая лента:
население имеет больший вес, категория/район доступны рядом.

Desktop: settings около220px, recommendations около290px, карта самая широкая.
Tablet: настройки/карта без узких колонок, рекомендации ниже. Mobile:
intro → KPI → settings → map → recommendations → saved, без page overflow.
Карта минимум420px. При 200% текста естественный перенос, не overflow:hidden.
Сравнение прокручивается внутри контейнера, заголовки таблицы читаемы.

Добавляемые стабильные hooks:
- #header-sentinel, .site-header.is-scrolled;
- #analysis-context рядом с KPI, #analysis-status в контрастной полосе карты;
- #analysis-progress с md-linear-progress и .progress-fallback;
- html[data-analysis-state] initial/calculating/refreshing/success/error.
Их отсутствие до реализации служит ожидаемым RED проверки нового интерфейса.

Native button/select/checkbox/range/dialog сохранены: JS читает value,
selectedOptions, checked, disabled и использует showModal/close. Реальный
Material-компонент — md-linear-progress во время расчёта. Он не требует
адаптера ввода. Остальные MD-контролы рассмотрены и не заменяют native автоматически.
Entry ограничивается фактически используемым progress, локальный bundle пересобирается.
При отказе bundle остаётся native progress fallback; API/настройки работают.

## Motion

Все состояния сначала устанавливают конечный DOM/ARIA, движение вторично.
Tokens: fast140ms/base220ms/slow420ms, stagger75ms; custom cubic-bezier.
Без GSAP/Framer Motion, scroll hijack, постоянных пульсаций и per-frame layout.
CSS keyframes для первого появления; Web Animations API для ответов на события.

1. Первый экран: короткое появление типографики, без длительной блокировки.
2. Карта: reveal после инициализации Leaflet; слои opacity на pane, не transform
   контейнера Leaflet. Загрузка тайлов имеет отдельный существующий fallback.
3. Loading: реальный indeterminate progress только пока запрос выполняется;
   refresh сохраняет предыдущий результат, первый расчёт имеет спокойный skeleton.
4. KPI: конечные числа выставляются сразу, короткий opacity/translate reveal.
5. Новые рекомендации: stagger0/75/150ms только для нового analysis_id.
6. Выбор: изменение карточки и короткий pulse внутреннего маркера, без изменения
   transform координатного wrapper Leaflet. Повтор того же rank не перезапускает pulse.
7. Кнопки: hover/press физичны, но не меняют layout и доступную область.
8. Сохранение: feedback только после успешной записи; новые saved карточки reveal.
9. Удаление/сравнение/пустые состояния: короткий уход snapshot и FLIP соседей,
   без отложенной мутации storage или скрытых интерактивных дублей.
10. Dialog: вход и выход; native Esc, focus и видимость меняются немедленно,
    анимация не задерживает close. При необходимости выход использует inert snapshot.
11. Inline notices: короткий reveal текста, без focus steal.
12. Custom area: мягкое раскрытие/скрытие без задержки актуального hidden/ARIA.

Программные Animation.id имеют префикс gm: для диагностики фактических эффектов.
При новых событиях прежний эффект элемента отменяется; rejected finished обработан.
При переключении prefers-reduced-motion все активные эффекты отменяются,
CSS движения выключены. MD indeterminate останавливается, видна статичная
семантическая индикация ожидания без выдуманного процента. Нет зависимости
корректности от animationend/finished. В print нет движений и ghost snapshots.

## Контракты и риски

Не менять backend/API/JSON/модель, geomarketing.saved.v1, CSV/print,
id/data-testid/доступные имена, отмену запросов и storage/Web Locks.
Исключения из общих дизайн-скиллов определяет пользовательский бриф:
светлая тема с локальной тёмной аналитической поверхностью; без React/Tailwind,
без искусственного hero image, декоративных маркетинговых блоков и forced dark mode.
Реальная карта является визуальным материалом. Taste применяется к композиции
и anti-template фильтру, а не как шаблон плотных таблиц.

Критические failure modes: проигравший запрос перезапускает loading;
анимация удерживает hidden/focus; дубли ghost вмешиваются в селекторы/storage.
Защита: существующий requestVersion, немедленный финальный DOM, inert/aria-hidden
snapshots без id/data-testid, cleanup на завершении/отмене. Reduced-motion
проверяется и при старте, и при смене предпочтения на ходу.
