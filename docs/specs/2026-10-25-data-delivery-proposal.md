# Доставка данных Липецка — предложение после диагностики Render

Статус: ожидает выбора пользователя; реализация не начата.

## Подтверждённая проблема

Локальное обновление получает свежие дома и конкурентов. Render отказывает в TCP-соединении с основным Overpass по IPv4; независимые публичные серверы возвращают 504 или не отвечают в срок. Три варианта подключения не дали свежего публичного результата. История проверки: `docs/verification/2026-10-25-data-refresh.md`.

## Предлагаемый вариант

GitHub Actions раз в сутки собирает одну городскую выборку жилых зданий и объектов всех поддерживаемых категорий. Публикуется проверенная выгрузка в репозитории; платные ресурсы и дополнительные аккаунты не требуются. При неудаче сбора остаётся последняя успешная версия с прежней датой.

Сайт получает выгрузку с GitHub по HTTPS, проверяет формат, границы, полноту и версию. Готовые и произвольные области фильтруются из городских данных. Жителей и рекомендации рассчитывает существующая модель. Хранится настоящая дата получения исходных данных; повторная загрузка того же файла не меняет её.

Кнопка «Проверить обновления» запрашивает последнюю опубликованную версию. Интерфейс различает новую версию, отсутствие изменений и недоступность источника. Пользователь видит периодичность и дату данных. Сохранённые исследования продолжают использовать собственный снимок.

## Что проверить до публикации

- Реальная сборка городских данных на GitHub, успешная загрузка этой версии с Render.
- Два последовательных обновления: новая версия и отсутствие более новой версии.
- Отказ сети, повреждённый/неполный файл и старая дата не затирают последнюю корректную копию.
- Все типы бизнеса, десять готовых областей и произвольная область используют прежние правила фильтрации, конкуренции и населения.
- Новая версия данных переживает перезапуск Render через внешнюю выгрузку.

## Альтернатива

Для получения данных непосредственно при нажатии потребуется доступный с Render поставщик Overpass с подходящими условиями, возможно с API-ключом. Конкретный провайдер и какие-либо платные услуги пока не выбраны.
