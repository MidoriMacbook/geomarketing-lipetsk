# Оформленные меню выбора

Запрос: браузерные меню области/бизнеса выбиваются из оформления и не имеют
анимаций. Существующую розово-сливовую палитру и остальные функции сохраняем.

Решение: постепенное улучшение трёх select (district/business/radius) общим
компонентом combobox без редактирования текста. Кнопка содержит иконку, значение
и стрелку. Отдельное светлое меню различает наведение, активный и выбранный пункты;
выбор отмечается галочкой. Раскрытие длится 360 мс, строки появляются за 220 мс
с последовательной задержкой. Закрытие за 220 мс использует существующий
неинтерактивный снимок с inert. При уменьшении движения сразу показывается конечное состояние.
Меню размещается в body с position:fixed, ограничивается видимой областью
и раскрывается вверх при недостатке места. Прокрутка внешней страницы, изменение
размера, переход фокуса за пределы компонента или выбор другого поля закрывают меню.

Нативный select остаётся источником значений, options и событий change для приложения;
после успешной инициализации скрывается и исключается из порядка обхода Tab.
Без модуля нативные поля доступны. Синхронизация с каталогом, отключение полей
и повторная загрузка сохраняются. Подпись и описание относятся к combobox;
состояния active descendant, listbox и option передаются доступно. Поддерживаются
стрелки, Home/End/PageUp/PageDown и поиск набором текста. Enter/Space/Tab подтверждают
выбор, Escape отменяет. DOM-фокус остаётся на кнопке, активный пункт прокручивается внутри меню.
Основа семантики: https://www.w3.org/WAI/ARIA/apg/patterns/combobox/examples/combobox-select-only/

Риски: рассинхронизация с каталогом предотвращается наблюдением за options, disabled
и change. Меню закрывается при смене района или скрытии radius. Выход за экран,
в том числе при 200% текста, предотвращается max-height, внутренней прокруткой
и переносами. Проверяются управление клавиатурой и работа нативных полей при отказе модуля.
Оформление только через CSS сохраняет системное меню в части браузеров;
новая зависимость для четырёх-пяти пунктов избыточна. Выбран локальный модуль.
Модель, API, хранилища и DOM-идентификаторы сохраняются. Прежние проверки контрактов
могут задавать значение скрытого select напрямую; новый сценарий использует видимые элементы.
