# Связанный рабочий сценарий

Основание — подробный запрос пользователя от 28 октября. Палитра, шрифты,
editorial-оформление, сервер/API/модель, Leaflet, форматы хранения и отчёты сохраняются.

## Решение

Hero сохраняет схему и назначение сервиса. Его прежняя кнопка становится
«Вернуться к карте», когда есть сохранённое место, исследование или выполненный
пользователем успешный расчёт этой сессии. Компактная строка поясняет источник
контекста. Автоматический стартовый расчёт сам по себе не делает визит повторным.
Приоритет: явно выполненный расчёт, затем последний по дате архив или место.
Данные не восстанавливаются; перезагрузка без сохранений начинает обычный визит.
Строка занимает зарезервированное место рядом с прежней кнопкой, без сдвига hero.

Причина — качественная формулировка только из проверенного explanation v1 и
базовых метрик. Нет собственного порога «мало конкурентов»: ноль называется явно,
положительное число сообщается фактически. До двух причин: жители в радиусе,
затем расстояние до центра спроса, затем плотность домов. Крупное число жителей
остаётся в метриках один раз; соответствующая причина занимает эту же строку.
На desktop та же семантика в компактной подписи. Относительный спрос всегда
обозначен как сравнение точек текущего расчёта. Неизвестное не классифицируется.

Единая панель сравнения видна на всех размерах, показывает число реально выбранных
существующими флажками мест. Телефон сохраняет прежнее добавление через тот же
флажок, desktop — ручной выбор. Лимит 3 не заменяет набор. Состояния 0/1/2/3
различимы; после второго явный переход. Из сравнения доступны карта, параметры
и прежняя кнопка сохранения исследования. Переходы не меняют расчёт/центр карты.

Сохранённые места остаются заметным списком точек. Исследования получают спокойную
иерархию архива полных снимков; данные — вспомогательный раздел. Телефон сохраняет
существующие details. Переносы DOM и focus между размерами остаются корректными.

## Риски и проверка

- Архивный контекст нельзя выдавать за текущий расчёт: виден тип источника,
  возврат только прокручивает и фокусирует карту.
- Удаление последней записи/внешнее storage-событие: подсказки пересчитываются,
  фокус не остаётся в скрытом блоке; новый формат localStorage не появляется.
- Быстрые переходы и reduced motion: штатный animateUI отменяет предыдущий эффект,
  навигация не ждёт animationend. Никакой автоматической прокрутки после сохранения.

Проверка: чистый визит, оба типа сохранений после reload, текущий расчёт/ошибка,
сохранения 1–3 и переполнение, ручные флажки, сравнение → карта/настройки/исследование,
legacy/повреждённые метрики, 320/390/430/768/1280 при 100/200%, reduced motion,
горизонтальный overflow, keyboard focus и JS errors; регрессии CSV/печати/архивов.
