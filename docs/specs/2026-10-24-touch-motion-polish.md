# Полировка взаимодействий — 24 октября 2026

Основание: подробное задание пользователя от 24 октября. API, математика,
каталог, Leaflet, сохранения, исследования и форматы CSV/печати не меняются.

## Навигация
Кремовый фон #FFF7E6 одинаков до/после scroll и при открытом меню. Меняется
только мягкая тень. Mobile ≤900px: абсолютная панель под header, grid 0fr→1fr,
opacity, y−8px; открытие400ms, закрытие300ms. Внутренний clip ограничивает
раскрытие, отдельный список прокручивается по доступной высоте. Пункты≥44px,
stagger40ms. Иконка из трёх линий превращается в крест.
Закрытое меню inert и aria-hidden; Escape/outside/focusout, focus return сохранены.
После выбора ссылки закрытие предшествует scroll; повторное открытие отменяет
отложенный переход. Reduce убирает ожидание. Desktop: общий перемещающийся
индикатор для текущей секции; обычная горизонтальная навигация.

## KPI
На каждой карточке отдельная нативная кнопка «Повторить» с полной областью
нажатия и именем «Повторить анимацию: [метрика], [точное значение]».
До получения числа кнопка отключена. Click/tap/Enter/Space: scale .985/180ms,
волна от касания560ms, линия600ms, визуальный откат6% и возврат560ms.
Для маленьких целых округление может оставить число неизменным: волна/линия
всё равно обозначают действие. Текст доступности и реальные данные неизменны.
Повторное нажатие сначала завершает старый счётчик, отменяет эффекты и начинает
новую реакцию. Reduce: только тональная заливка, без движения/чисел.

## Остальные состояния
Press-feedback у select-trigger, слоёв, расчёта; открытие селекта через y8/opacity,
поворот стрелки; метка и галочка выбранного варианта. Native select/change/ARIA
сохранены. Skeleton появляется однократно, progress показывает реальное ожидание.
Tap по рекомендации: Blush, Rosewood-полоса360ms и один marker pulse420ms.
Сохранение подтверждается после записи, размер кнопки стабилен, галочка раскрывается.
Прерываемые disclosures используют clip-path и поворот chevron.

## Hero и шрифты
Нет пользовательской кнопки паузы и бесконечной пульсации. Маршрут один раз4s,
ответ точки900ms; автоматическая приостановка вне viewport/hidden/print/reduce.
Компактная мобильная SVG сохраняется. Playfair Display: hero и крупные заголовки;
Onest variable100–900: формы/обычный текст; системный mono: числа/координаты.
Onest локальный WOFF2, кириллица/латиница, OFL1.1, hashes и источники рядом.
Mobile body/пояснения16px, line-height1.55. Шрифты не загружаются с CDN в runtime.
