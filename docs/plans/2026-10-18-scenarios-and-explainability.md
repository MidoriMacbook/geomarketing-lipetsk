# Исследования и объяснимость — итоги 18 октября 2026

[Спецификация](../specs/2026-10-18-scenarios-and-explainability.md) определяет полный локальный снимок расчёта, объяснения рекомендаций, качество данных и сравнение двух исследований.

Сервер добавляет `calculated_at`, `analysis_context`, `data_quality` и `recommendation.explanation`, сохраняя прежние поля, численные результаты и алгоритм `scoring.py`. Объяснения основаны на тех же формулах спроса и конкуренции, а не на прогнозе прибыли.

`scenario-storage.js` хранит до шести исследований в `geomarketing.scenarios.v1`: максимум 250000 символов JSON на запись и 1250000 на ключ. Проверка схемы, чтение актуальных данных внутри Web Lock и отдельное подтверждение очистки повреждённого ключа защищают записи. Без Web Locks доступны чтение и экспорт. Старые сохранённые места не мигрируют.

`scenarios.js`, `data-quality.js` и `scenario-report.js` отвечают за список, объяснения и отчёты; `app.js` восстанавливает проверенный снимок без запроса API и игнорирует поздние ответы. Сравниваются ровно два исследования без ранжирования относительных оценок. Прежние 17 колонок CSV мест сохранены; дополнительные сведения о качестве добавлены справа.

Историческая проверка включала формулы и пороги, даты и источники, старые API-результаты, повреждённые записи/квоту/две вкладки, неизвестные версии, отсутствие блокировок, восстановление своей области без сети, поздние ответы, CSV и печать. Проверялись 360/390/768/1440 px, 200% текста, касания, клавиатура, уменьшение движения и отказы Leaflet/API/хранилища. Выпуск использовал GitHub Actions и существующий Render.

Исследования сохраняются только в этом браузере; синхронизация устройств и серверная база не вводились.
