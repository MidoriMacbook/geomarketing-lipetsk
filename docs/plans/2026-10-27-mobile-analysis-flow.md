# План мобильного сценария

[Требования](../specs/2026-10-27-mobile-analysis-flow.md).

- [x] Воспроизвести отсутствие компактного мобильного сценария браузерной проверкой.
- [x] Сохранить единственную форму в доступной нижней панели, адаптировать меню выбора.
- [x] Уплотнить KPI, вступление и рабочую область; сохранить планшет и компьютер.
- [x] Добавить раскрытие рекомендаций с сохранением действий и данных.
- [x] Проверить целевые размеры, касания, клавиатуру, ошибки, 200%, уменьшение движения.
- [ ] Проверить прежние функции, документацию, соответствие требованиям.
- [ ] Опубликовать и проверить Render.

Взаимодействие модулей: mobile-workspace.js управляет переносом существующих
элементов и диалогом; recommendations.js отвечает за карточки. События
`gm:analysis-rendered` и `gm:recommendation-selected` сохраняют свои контракты.
Мобильный режим действует до 600px, а также на сенсорном экране до 950px
при высоте до 500px. Обычный планшет 768×1024 сохраняет прежнюю компоновку. Стили новых элементов
ограничены этой границей; на больших ширинах они скрыты.
