# Мобильный путь и понятность рекомендаций

Основание — задание владельца после завершения истории. Дизайн сохраняет текущие
тёплые токены, Onest/Playfair, карту и модель. Работа — исправление наблюдённых
препятствий без новых бизнес-функций. Первый аудит выполнен на публичном сайте.

- [x] Зафиксировать шесть подтверждённых препятствий и исходные снимки 360/390/430/320.
- [x] RED → GREEN: готовый расчёт/архив/неприменённая форма различаются; существующая
  кнопка настроек доступна над картой, один dialog и корректный возврат на wide.
- [x] RED → GREEN: контекст рядом с рекомендациями, конкретные факты в свёрнутых
  карточках, вторичный балл, без повторяющегося объяснения шкалы в каждой карточке.
- [x] Скрыть повторную сводку на телефоне, сохранить подробности и проверки на месте;
  существующие переходы к настройкам/карте/сравнению остаются доступны.
- [x] Пройти основной путь, быстрые открытия/закрытия и reduce; проверить 320–430,
  desktop и увеличенный текст. Сравнимые before/after — на одном контролируемом API.
- [x] Независимое ревью, existing smoke и целевые регрессии, профильные JS-тесты,
  проверка импортов/DOM. Обычная публикация и проверка Render/CI.

Не охвачено: физические iOS/Android, реальный поток клиентов/аренда, новые категории,
изменение модели, объединение домов. Риски: изменение ширины не должно терять форму
или фокус; контекст результата нельзя подменять параметрами ещё не применённой формы;
скрытие повторов не должно удалять сведения из CSV/печати/сохранений.
