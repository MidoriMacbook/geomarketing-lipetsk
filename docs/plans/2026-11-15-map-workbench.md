# Интерактивная карта и мобильные результаты

Ветка `redesign`, исходная версия `414c71e`. Сервер, формула расчёта и формат API неизменны. Отдельные содержательные коммиты с короткими русскими названиями. Публикация только preview redesign.

Приоритет последнего сообщения: пин открывает выноску, а не панель; «Подробнее» открывает полный список. Главная новая возможность — проверка и сохранение произвольной точки на клиенте. Приложенный промт сохраняет силу для остальных пунктов.

## Важные технические условия

Клиент должен использовать ту же локальную метрическую проекцию, что и существующий расчёт: 111000 м/градус широты и множитель cos(latitude центра области) для долготы. Haversine/Leaflet distance дают немного другой радиус и не подходят для точного совпадения карточек.

Сетка уже содержит нормированные значения. Билинейное значение совпадает с узлом сетки в самом узле; произвольная точка между узлами не обязана совпадать с ближайшим узлом с допуском 1 балл. Проверять оба свойства отдельно, не подменять интерполяцию ближайшим соседом.

Старые сохранения и исследования должны оставаться читаемыми. Ручное место получает отдельный идентификатор и отметку происхождения, не занимает rank серверной рекомендации и не меняет снимок анализа.
