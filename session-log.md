## 2026-10-17 Гармония карты, mobile и отказ от typewriter [saved]
Goal: Близкие к референсу, различимые маркеры; отступы телефона; обычная анимация h1.
Decisions:
- Яркие blue/coral/gold пользователь отверг. Домам возвращена насыщенная пыльная
  роза #C58CA6, конкурентам ягодный #B94F7B/светлый outline, кольцам #E4D2EE.
- Зоны сливовые #4A3F4B→#8C709A; различимость обеспечивают светлота, обводки/формы.

  intro.js удалён, h1 использует общий CSS intro-reveal900ms, reduced/print выключают.
- Проверка сохраняет карту/AX/geometry из прежнего теста, обновляет только typing
  expectations; RED→GREEN. Счётчики сохраняются и отдельно подтверждены браузером.

- Чуждые яркие функциональные цвета; старая бледная роза без усиления/обводок.
- Typewriter и ненужный session flag после явного отказа пользователя.
Open:
