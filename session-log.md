# Журнал решений

## 2026-10-17 Контраст и печатающийся h1 [saved]
Goal: Сохранить понравившуюся палитру и устранить слияние карты/разделов.
Decisions:
- Настройки на пудровой панели с тёмными подписями; карта, KPI, рекомендации,
  сохранения имеют собственные поверхности/границы/заголовки.
- Цвет бренда и аналитические роли разделены: голубые дома, коралловые конкуренты,
  золотые пунктирные кольца скоплений, прозрачные лиловые зоны, розовые номера.
- Общий --color-settings сохранён тёмным для прежних controls; light panel token
  отдельный. Selection использует независимые цвета, иначе scope давал1:1.
- H1 печатается один раз во вкладке,38ms на символ; полный AX label и геометрия
  сразу. После завершения/отмены восстанавливаются исходные text nodes.
- Без storage — once-per-load, reduce/print/hidden/error раскрывают всё сразу.
- Mobile KPI старые edge-padding overrides удалены, цифры36px и отступ16px.
Rejected:
- Светлый фон всего сайта; усиление одних рамок при неразличимой карте.
- Изменение доступного текста по букве, бесконечные typewriter loops, зависимости.
- Гипотеза unhandled rejection при third animation throw: browser test её не подтвердил.
Open:
- Полный аудит разных screen readers/Firefox/Safari/native PDF не выполнен.

## 2026-10-17 Числа и палитра с референса [saved]
Goal: Продолжить заметные анимации и применить присланную пользователем гамму.
Decisions:
- Тёмная основа #16131F и розовый #F0D9E4; остальные оттенки референса в токенах.
- Выбранную поверхность затемнили до #3D3340: muted текст даёт5.092 вместо4.226.
- Числа1100ms, viewport start; точный DOM/ARIA сразу, промежуточный overlay aria-hidden.
- Refresh переносит видимое значение карточки по lat/lng/radius до замены DOM;
  смена фильтра очищает историю. Один RAF, без layout reads на кадре.
- KPI label styles ограничены прямыми детьми, чтобы новые span не получили12px.
- Независимое ревью нашло и закрыло refresh/контраст; старый map performance test
  сохранён, selected contrast вынесен в отдельный изолированный browser context.
Rejected:
- Фото сакуры как фон рабочей карты: пользователь прислал цветовой референс.
- Перезапуск одинаковых чисел и изменение доступного текста на каждом кадре.
Open:
- Полный аудит screen readers, Firefox/Safari и native PDF вне текущей проверки.

## 2026-10-17 Тёмная версия [saved]
Goal: Исправить отвергнутый пользователем светлый фон и незаметные анимации.
Decisions:
- Пользователь явно выбрал предложенные графит/бирюзу («попробуем твой вариант»).
- Входы ждут viewport: прежние эффекты тратились ниже экрана на y≈2300.
- Более выразительные700–900ms входы, быстрые действия; доступность DOM сразу.
- OSM остаётся прежним; grayscale filter только tiles, цветные слои отдельно.
- Reduced-motion очищает активные и ожидающие эффекты; печать светлая.
- Main/Render опубликованы после проверки; doc-only audit skip render.
Rejected:
- Очередная светлая вариация, простое увеличение длительности без исправления viewport.
- Новый map provider, новые motion библиотеки и scroll hijacking.
Open:
- Native PDF/OS dropdown/Firefox/Safari вне выполненной Chrome-приёмки.

## 2026-10-16 [saved]
Goal: Обновить визуальный язык и motion ГеоМаркетинга без изменения функций.
Decisions:
- Минеральный фон, графит и терракота заменяют зелёную UI-палитру по прямому заданию пользователя.
- Лайм обозначает выбранные точки; функциональные цвета карты остаются отдельными.
- Native controls сохраняют контракты; Material progress обслуживает реальный расчёт с fallback.
- Конечный DOM меняется сразу; отменяемые анимации не управляют storage, focus и корректностью.
- Все motion эффекты учитывают reduced-motion, включая смену предпочтения во время работы.
Rejected:
- React, Tailwind, shadcn, GSAP и копирование Skiper-компонентов.
- Бесконечные маркерные пульсации и задержка доступности ради анимации.
Open:
- Проверить итоговый вид трёх ширин и native print ограничения.
