# ГеоМаркетинг Липецк

[Открыть сайт](https://geomarketing-lipetsk.onrender.com)

Помощник выбора места для малого бизнеса. Сравнивает жилую застройку и
конкурентов в выбранной области, показывает центроиды спроса и до трёх мест
для проверки помещения и окружения.

## Возможности и ограничения

- Десять готовых областей либо центр и радиус на карте. Смена готовой области
  автоматически пересчитывает результат; для нового бизнеса нажмите «Найти места».
- Десять категорий: кофейня, аптека, продуктовый магазин, пекарня, салон красоты,
  быстрое питание, цветочный магазин, зоомагазин, фитнес-студия, стоматология.
- KPI временно выделяют связанные слои, а существующая строка статуса объясняет
  выделение. Повторное нажатие или Escape снимает акцент без изменения фильтров.
- Карточки и маркеры связаны; сводка объясняет спрос, конкуренцию, ближайшего
  конкурента и то, что нужно проверить на месте.
- До 12 сохранённых мест, сравнение до трёх, CSV и печатный отчёт.
- До 6 исследований с полным снимком расчёта и настроек, названием и заметкой.
  Открытие восстанавливает архив без нового запроса; можно сравнить два исследования.
- Семь отметок проверки помещения и окружения у сохранённого места.
- Ежедневная городская выгрузка OpenStreetMap через GitHub Actions. Кнопка
  проверяет наличие новой версии и сохраняет настоящую дату исходных данных.
- Локальные шрифты Onest/Playfair Display, React Bits, Material Web, Leaflet и
  фирменные иконки SVG/PNG. При сбое необязательной анимации содержимое доступно.

Готовые области: Елецкий, Университетский, Центр (Быханов сад), Победа,
Европейский, Сокол, НЛМК, Тракторный, Матырский, Сырский Рудник. Это круги
радиусом 1 км вокруг жилых ориентиров, а не административные границы.

Население оценочное, расстояния прямые. Оценки сравнимы только внутри одного
расчёта и не означают вероятность успеха. Радиусы и штрафы конкуренции —
эвристики. Помещения, аренду, маршруты и поток людей нужно проверить на месте.
Сохранения находятся в этом браузере; синхронизации между устройствами нет.
Карта использует внешние плитки OSM, которым нужен интернет.

На телефоне откройте карту и нажмите «Настроить анализ»: район и бизнес находятся
в нижней панели. «Найти места» закрывает её после успешного расчёта. Две основные
цифры видны сразу, дома и конкуренты — в «Деталях области». Лучшее место раскрыто;
остальные открываются нажатием. «Показать на карте» возвращает к выбранной точке.
Сохранённые места и исследования раскрываются отдельно. На планшете и компьютере
форма остаётся рядом с картой.

Раскрытия и нижняя панель поддерживают быстрые повторные нажатия и уменьшение
движения. При ошибке нового расчёта прежний результат остаётся с исходными районом
и бизнесом; новые параметры сохраняются в форме для повторной попытки.

Рекомендация объясняется учтёнными конкурентами, оценкой жителей в радиусе
и близостью центра спроса; число жителей показано крупно один раз. «Сохранить для сравнения» сохраняет точку и выбирает её прежним флажком,
пока не достигнут лимит трёх. Панель открывает таблицу только по нажатию.
Четвёртая точка сохраняется без замены выбранных; на широком экране выбор ручной.
Панель показывает именно выбор для сравнения на всех размерах. Из таблицы доступны
карта, параметры и сохранение исследования. Сохранённое место — одна точка;
исследование — полный снимок расчёта. Архив и источники оформлены спокойнее.

При повторном визите hero предлагает вернуться к карте по контексту сохранённого
места или исследования; после явного расчёта — продолжить текущую работу.
Возврат только прокручивает страницу и фокусирует карту, без открытия архива.
Несохранённый расчёт остаётся только в открытой сессии.

Направления используют единые локальные иконки: раскрытие, переход,
внешняя ссылка и скачивание. Нативные маркеры details убраны, поворот и
aria-expanded отражают состояние; при уменьшении движения поворот мгновенный.
[Полировка и снимки до/после](docs/verification/2026-10-29-visual-polish.md).

Действия KPI и карточек не подчёркиваются; выбор виден по подписи и aria-pressed.
[Мобильные действия](docs/verification/2026-10-29-mobile-actions-and-audit.md) и
[аудит достоверности](docs/verification/2026-10-29-data-reliability.md) описывают
проверенные свойства и ограничения исходных данных и относительной модели.

## Локальный запуск

Нужен Python 3.14. Из корня проекта:

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe serve.py
```

Linux/macOS:

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python serve.py
```

Откройте http://localhost:8080. Waitress слушает 0.0.0.0; `HOST` и `PORT`
задаются окружением. `python app.py` запускает локальный вариант на
http://127.0.0.1:5001 без отладчика по умолчанию.

Для городской выгрузки задайте переменную перед запуском:

```powershell
$env:CITY_DATA_URL='https://raw.githubusercontent.com/MidoriMacbook/geomarketing-lipetsk/osm-data/city.json'
.venv/Scripts/python.exe serve.py
```

На Linux/macOS используется та же переменная окружения. Без неё действует
прежний локальный режим Overpass и районных снимков. Настройки кэша и публикации:
[DEPLOYMENT.md](DEPLOYMENT.md). Сервер и API обслуживаются одним сайтом;
адресов localhost в клиентском коде нет.

## Сборки интерфейса

Основные ES-модули не требуют сборщика. Готовые сборки Material Web и анимаций
первого экрана включены в Git; для обычного запуска Node.js не нужен.
При изменении исходников соответствующей сборки:

```bash
pnpm install --frozen-lockfile
pnpm run check:material
pnpm run check:hero
```

Проверяются воспроизводимость, исходники и бюджет анимационной сборки 180 KiB gzip.
Источники и лицензии находятся рядом с локальными сборками.
[Material Web](docs/design/material-web.md) · [Клиентская архитектура](docs/architecture/frontend.md).

## Исследования, хранилища и отчёты

Исследование хранит расчёт, выбранное место, порог и слои. «Открыть» восстанавливает
копию, а «Найти места» создаёт новый расчёт и не перезаписывает архив. Название
и заметка изменяются отдельно. CSV — выгрузка сведений, а не импортируемая копия карты.

Ключи `geomarketing.saved.v1`, `geomarketing.scenarios.v1` и
`geomarketing.field-checks.v1` сохраняются. Для исследований действует
`schema_version:1`, лимит 250000 символов JSON на запись и 1250000 на список.
Квота браузера может быть меньше. Ошибка записи сохраняет исходные данные;
повреждённый или неизвестный формат не перезаписывается. Доступны исходный JSON
и подтверждаемая очистка. Без Web Locks чтение и экспорт доступны, запись отключена.

Объяснения и качество данных используют существующую модель. Возраст каждого
набора определяется исходной датой; сохранение архива не делает данные свежее.
Старые записи без дополнительных сведений остаются читаемыми с отметкой «не оценено».

## Проверки

```bash
python -m unittest discover -s tests -v
python -m py_compile app.py serve.py osm.py businesses.py
python scripts/validate_project.py
node --test tests/unit/scenario-storage.test.js tests/unit/field-check-storage.test.js tests/unit/data-delivery.test.js tests/unit/analysis-focus.test.js tests/unit/recommendation-brief.test.js
```

Серверные тесты работают без сети. GitHub Actions также проверяет синтаксис
клиентских модулей и воспроизводимость сборок на Linux, Node 24, pnpm 11.25.0.

Браузерные сценарии запускаются после локального сервера в чистом сеансе:

```bash
playwright-cli -s=geomarket open http://127.0.0.1:8080
playwright-cli -s=geomarket run-code --filename=tests/browser/workspace-guidance.js
playwright-cli -s=geomarket run-code --filename=tests/browser/workspace-guidance-fallbacks.js
playwright-cli -s=geomarket run-code --filename=tests/browser/workspace-interactions.js
playwright-cli -s=geomarket run-code --filename=tests/browser/palette.js
playwright-cli -s=geomarket close
```

Проверяются KPI, карта, клавиатура, касания, увеличенный текст, уменьшение движения,
сохранения, исследования, CSV и печать. Исторические матрицы каталога, меню и
анимаций находятся в tests/browser. Плиткам карты нужен интернет; успешная
проверка интерфейса не подтверждает полноту OSM и работу физического принтера.
